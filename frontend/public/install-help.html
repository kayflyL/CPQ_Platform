把 CPQ 装到手机桌面

一次性安装,之后点桌面图标直接进,全屏无浏览器栏 —— 与正常 App 一样

安卓Chrome / Edge需先装 CA 证书

看到「无法安装此应用」?说明你还在 5173 或证书没装——HTTP 站点永远装不了,必须走完下面步骤从 5443 进。

  1. 下载证书文件
    ① 下载 CA 证书
  2. 安装证书:手机「设置」搜索「安装证书」→ 选 CA 证书 → 选中刚下载的 cpq-ca.crt → 确认(可能要求锁屏密码)
  3. 彻底退出 Chrome 再重新打开(后台划掉重开,必做)
  4. Chrome 打开 https://10.32.39.132:5443 → 右上角 ⋮ → 「安装应用」或「添加到主屏幕」→ 安装
  5. 桌面出现 CPQ 图标,点开即全屏 App。网址里的安全提示在装完证书后消失

必须用 Chrome 或 Edge;微信/QQ 内置浏览器装不了 —— 从微信收到链接时,先右上角「在浏览器打开」。

iPhone / iPadSafari

  1. 用 Safari 打开 http://10.32.39.132:5173(不用装证书)
  2. 点底部中央分享按钮(方框加向上箭头)→ 往下滑点「添加到主屏幕」 → 添加
  3. 桌面出现 CPQ 图标,点开即全屏 App

从微信收到链接:先点右上角「…」→ 选择「在 Safari 中打开」,再从第 1 步做起。

装好之后

  1. 日常从桌面图标进,不再需要记任何网址和端口
  2. App 的登录状态和浏览器是分开的,装好后第一次要重新登录,之后长期保持
  3. 页面更新都发生在服务器端,重新打开 App 即是最新版,无需在手机上更新任何东西

打不开 5443?说明证书流程还没就绪,可先用浏览器访问 http://10.32.39.132:5173 ,不影响使用。
