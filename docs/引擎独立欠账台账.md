## 五、优先级结论

**主线（v4 办公室切换版，2026-10-31 定调，详见 AI办公室引擎化方案.md §6 v4）**：第 1 步装注册插座（原刀一 BUILDERS 注册 API + 融合区基线快照锁，解 flow_validation+skill_node_artifacts 两账）→ 第 2 步办公室档案壳（「全局办公室」改名「CPQ办公室」+ offices 档案 + 管理面按办公室过滤）→ 第 3 步空办公室演练（出四原语缺口与融合模块两份清单）→ 第 4 步 AI 接入向导（等真实新系统）。~~刀二 CPQ 设置页"中间层"栏目~~（**2026-10-31 定调不做**，原型留档即止）。**其余全部挂账带扳机**（v4 执行表）：融合区解耦=演练清单拉动、轮壳注入=重构窗口、四原语=演练清单或真实审批办公室、探针 DSL=第三条事务流、写后回读=随域接入。
