

## 一、整体架构分层（业务层 + VueFlow 画布层 + 后端存储层）

### 1）业务规则实体（核心数据结构，画布全部基于这套数据渲染）

报价加价规则由**5 个维度主键 + 加价规则 + 生效优先级 + 阈值区间**构成

表格

| 维度          | 枚举划分                                 | 加价规则类型                                 |
| ----------- | ------------------------------------ | -------------------------------------- |
| 客户行业        | 政企、金融、教育、医疗、互联网、智能制造、IDC 机房、安防、通用商用  | 成本百分比加价 / 阶梯加价（成本越高点位越低）               |
| 客户区域        | 国内（华东 / 华北 / 华南 / 西南等）、境外（东南亚、欧美、中东） | 基础利润点 + 地区浮动附加费（境外客户加点更高）              |
| 芯片平台        | AMD（Orion系列）、兆芯（Polaris系列）           | 平台基准利润率（兆芯国产化项目溢价空间更高，AMD 市场化竞争激烈点位偏低） |
| 形态          | 2U、4U、5U                             | 4U整体成本比2U高，加点不能太狠                      |
| 客户等级 / 项目类型 | 集采招标、散单零售、长期框架协议、样机测试单、渠道分销、直客项目     | 优先级权重（集采最低毛利，样机最高毛利）                   |

额外附属规则：BOM 部件拆分加价（CPU / 内存 / 硬盘 / 机箱分开加点 + 整机打包加点）、批量数量阶梯折扣、账期加价（账期越长利润上浮）

### 2）VueFlow 定位：**可视化配置画布，用来拖拽编排报价规则链路**

不用 VueFlow 做计算，只用它做**规则流程图可视化编排、规则节点配置、规则执行流向、优先级拓扑管理**

- 左侧物料栏：各类规则节点（行业节点、区域节点、芯片平台节点、加价计算节点、条件分支节点、兜底默认规则节点）
- 中间画布：拖拽节点连线，形成「匹配条件→计算加价→结果输出」的完整策略链路
- 右侧面板：选中节点弹窗配置参数（利润率数值、区间、生效状态、优先级）
- 底部：画布校验、规则导出 JSON、预览报价演算效果

## 二、画布节点拆解设计（VueFlow 可直接落地的节点类型）

### 节点大类

1. **条件匹配节点（判断类）**
    
    - 行业筛选节点：下拉勾选适用行业
    - 地域筛选节点：国内分区 / 海外片区选择
    - 芯片平台节点：单选 Orion / Polaris
    - 项目属性节点：集采 / 渠道 / 直客 / 样机
    - 多条件合并节点：且 / 或逻辑（多维度同时匹配才生效）
    
2. **利润计算节点（运算类）**
    
    - 百分比加价节点：输入基准毛利率（例：Polaris政企 18%，Orion 互联网散单 10%）
    - 阶梯加价节点：填入多段成本区间对应毛利（成本 0~5w 毛利 15%；5w~20w 毛利 12%；20w 以上毛利 9%）
    - 叠加计算节点：多个加价规则累加（平台基准毛利 + 地区溢价 + 项目类型修正值）
    - 封顶 / 保底节点：设置最低毛利红线、最高加价上限，防止异常报价
    
3. **分支 & 流转节点**
    
    - 分支连线：匹配成功走 A 加价方案，匹配失败走 B 方案
    - 优先级权重节点：多条规则同时命中时，权重数字越大优先执行
    - 兜底默认节点：所有规则都不匹配时，加载系统默认通用利润率
    
4. **输出预览节点**
    
    接入测试成本值，实时算出：裸成本→各项加价叠加→最终报价→毛利额 & 毛利率展示

### 连线逻辑示例（一条标准报价链路）

`开始节点` → 行业条件 (政企) + 地域 (国内) + 芯片 (兆芯)【多条件合并】 → 兆芯基准毛利 17% → 政企项目上浮 2% → 阶梯成本修正 → 保底毛利不低于 12% → 输出报价规则

## 三、多维度加价差异化策略（贴合服务器行业真实业务）

### 1、芯片平台基准毛利（底层基础值）

表格

| 平台      | 业务场景              | 基准毛利率建议 | VueFlow 配置值                   |
| ------- | ----------------- | ------- | ----------------------------- |
| 兆芯（国产化） | 党政、国企、信创项目        | 10%~15% | 节点配置区间，招标集采取下限 15%，零散项目给到 22% |
| 兆芯      | 渠道分销走量            | 8%~12%  | 分销强制压低点位，依靠走量                 |
| AMD     | 互联网、IDC、算力租赁、商用项目 | 9%~14%  | 市面竞品多，价格透明，毛利偏低               |
| AMD     | GPU 整机、定制化算力节点    | 13%~18% | 定制方案、施工调试附加价值高                |

### 2、行业叠加浮动值（在平台基准上 ± 浮动）

- 政企信创：+3% ~ +5%（合规溢价、服务质保溢价）
- 金融 / 医疗：+2%（合规资质、维保要求高）
- 互联网 IDC：-2%（充分竞价，走量优先）
- 教育项目：持平基准，少量浮动
- 智能制造工业服务器：+1%~+3%（现场部署调试成本高）

### 3、地区加价规则

- 国内全境：无附加固定费，只用百分比浮动
- 海外项目：百分比毛利不变，叠加**固定费用**（报关费、国际物流、海外质保成本），同时汇率损耗额外 + 1%~2% 毛利补偿
- 偏远国内区域（西北、西藏等）：物流成本上浮，整体 + 1% 加价

### 4、订单模式修正系数

- 公开招标集采：整体毛利 × 0.7~0.8（压价严重）
- 长期框架协议：毛利 × 0.85~0.9
- 直客零散项目：毛利 × 1.0
- 样机测试订单：毛利 × 1.3~1.5（小单、售后对接成本高）
- 渠道分销出货：毛利 × 0.6~0.75

### 5、阶梯成本管控（防止大单毛利崩盘）

在计算节点内配置阶梯：

1. 整机 BOM 总成本＜5 万元：执行最高档位毛利
2. 5 万～30 万：中档毛利
3. ＞30 万大型整机柜批量订单：最低档位毛利
    
    同时配置**毛利保底红线**，无论阶梯怎么降，实际毛利率不能低于安全线（一般服务器硬件兜底 6%~8%）

## 四、VueFlow 代码层面落地实施步骤（Vue3 + TS）

### 步骤 2：拆分三层代码

1. **节点自定义组件**：分别封装条件节点、计算节点，props 绑定规则配置参数
2. **初始画布数据（nodes/edges）**：预置一套默认报价模板流
3. **规则解析引擎（纯 TS 函数，核心）**
    
    VueFlow 只负责画图，**真实报价计算必须单独写解析函数**
    
    流程：读取画布所有节点连线关系 → 递归遍历匹配条件 → 叠加所有加价系数 → 输入成本自动算出销售报价

> 禁止把计算逻辑写在画布内部，画布只是可视化视图，计算解耦便于单元测试、后端同步存储

### 步骤 3：数据持久化

画布 JSON（nodes+edges）存入后端数据库，每条策略绑定策略名称、生效时间、操作人员；报价系统拉取 JSON 交由解析函数运算报价。

### 步骤 4：配套预览调试面板

在画布侧边增加「成本输入框」，输入一台服务器裸成本，根据当前画布配置的整套策略，实时回显：

基础成本 → 平台加点 → 行业加点 → 地区加点 → 订单模式修正 → 阶梯折减 → 最终报价、毛利金额、毛利率

### 步骤 5：规则冲突处理（VueFlow 拓扑排序）

多条规则同时命中同一台服务器配置时，依靠节点内的`priority`权重字段做拓扑排序，高优先级规则覆盖 / 叠加低优先级规则

## 五、业务落地优化方案（贴合你方案中心日常工作）

1. **规则分组管理**
    
    VueFlow 画布支持多标签页，不同画布对应不同报价方案：信创专用报价策略、AMD 算力报价策略、海外项目报价策略、渠道分销策略
2. **规则锁定 / 启用开关**
    
    节点增加启用开关，临时停用某条加价规则不用删除画布节点
3. **BOM 分项加价拓展**
    
    不止整机加价，可拆分 CPU、内存、硬盘、网卡各自独立配置加价规则，通过 VueFlow 多分支分别计算部件利润再汇总整机价格
4. **对接现有报价系统**
    
    画布导出规则 JSON → 后端解析 JSON 生成计算函数 → 现有 CPQ 报价系统传入 BOM 成本自动计算售价，实现可视化配置、无代码修改加价点位，不用每次改代码
