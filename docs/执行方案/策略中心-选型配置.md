1，功能：服务于报价工作台，功能由简及繁，先做基础功能
2，页面布局，卡片式，一个规则一个卡片，点击编辑查看详情，详情页左侧栏编辑规则，右侧栏展示规则拓扑图
3，核心原则：拒绝黑盒，从规则名，到规则，到计算方式等，都要可视化，可配置，直观简单，分区分层清晰，用户可以自己新增或删除规则，因此每张规则卡不能出现比如针对GPU线缆一个布局，针对背板又一个布局的情况
4，第一期要添加的规则：
1）GPU线缆相关：每当服务器Key Part中配置了一个GPU显卡，那么机箱就要同步配一根GPU电源线；
2）背板相关：配置含 NVMe 盘 → 三模(tri)背板（tri 支持 SATA/SAS/NVMe）；纯 SATA/SAS 或无盘 → dc 直连兜底
3）机箱前面板线缆：需要能够根据用户配置的硬盘类型，选择前面板线缆，SATA盘配SATA线，SAS盘配SAS线，NVMe盘配NVMe线。具体而言，每8个SATA盘为一组，机箱配置的第二步前面板配置里，就要加1个SATA线，SAS盘同理，NVMe盘特殊，每2个NVMe盘为一组，增加1个线缆。
4）基准配置筛选相关：商机信息栏选了平台类型（如 Polaris），工作台/server config 只出现该系列机型
