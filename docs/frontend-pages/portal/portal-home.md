# 统一门户首页（Portal Home · 工作台三层架构）

> 最后更新：2026-10-13（主入口强化 v2 落地：右栏「我的工作台」入口卡=全页唯一主 CTA；流程条回归一条线纯展示；方案助手降格为常用功能磁贴；「我的任务」磁贴移除）（三层结构定稿：信号波纹 banner + CPQ 业务流程条 + 常用功能；原型 docs/prototypes/工作台-主入口强化原型.html）

## 功能概述

全员登录后的 **工作台**（`/portal`，首页），2026-09-28 定稿为**三层结构**（历经磁贴墙/数据墙/流水线/拼贴等多轮原型后收敛，原型见 docs/prototypes/）：

1. **信号波纹 banner**（非卡片：负让位垫入透明顶栏下、全视口宽、底部渐隐融入页面底色）：时段问候 + 欢迎语 + 概括角标（**今日待办**=角色口径非中性计数和；**第 2 枚**：admin=在办商机（全局 stages.running），非 admin=经手商机（items.involved，任一节点经手/fae 归属，含历史）；**今日新增**=admin 专属；真实口径 todo-summary）；右侧雷达环 + 旋转扫描扇 + 信号点脉冲（纯 CSS，prefers-reduced-motion 自动关）；右上 slogan 位。
2. **CPQ 业务流程条（纯展示）+ 右栏「我的工作台」入口卡**：流程条回归一条线原布局，五节点全局计数（stages，所有角色同口径），**不可点**——不再承担入口职责，卡头注明「数字为全公司在办口径」；右栏入口卡=**全页唯一主 CTA**（原型 v2）：角色铭牌（角色 · 环节）+ 三项个人统计 + 主按钮「进入工作台」。统计与子页统计条**同一接口同一口径**：business=`/opps` summary（待办事项/流转中/全部商机）、te/cost/quote=`/opps?mode=involved&node=`（待办事项/今日完成/经手商机）、admin=`/dispatch`（无主任务/活跃任务/今日转交）。director/member 无卡 → 流程条单列（solo）。
3. **常用功能 2×4**：**方案助手磁贴置首**（AI 渐变识别，`chatRolesAllowed` 门控，唤起全局浮动助手）；其余=商机线索 / 报价工作台 / 服务器 / 配件 / 选型配置 / 报价策略 / 解决方案 / AI 办公室——大行动行，按 `page.*` 权限过滤；**报价工作台 / 报价策略两张门槛=`field.quote.price`（价格视野）**。「我的任务」磁贴已移除（与右栏入口卡同目标，三入口互稀释）。全部为真实页面入口（无假动作）。

要点：**计数单一出处**（概括角标用角色口径、流程条用全局 stages，互不重复）；**零编造内容**（不放场景插画/假数据/水印图标，多轮试验的收敛结论）。材料与全站玻璃体系同源。

## API

| 方法 | 路径 | 用途 |
|------|------|------|
| GET | `/api/portal/todo-summary` | 返回 `{role, items, stages}`：items=角色口径计数（hero 角标），stages=五节点全局分布 + `running`（hero「在办商机」角标，2026-10-12 起全角色给出） |
| GET | `/api/portal/opps` | 各工作台子页列表（见 [workstation.md](workstation.md)） |
