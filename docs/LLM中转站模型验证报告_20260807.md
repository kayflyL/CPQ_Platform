# LLM 中转站模型真实性验证报告

- 日期：2026-08-07
- 被测端点：`http://api.cloudprime.com.cn:5567/v1`（中转站，下称 cloudprime）
- 被测模型别名：`deepseek-v4-flash`（官方对应 DeepSeek-V4-Flash-0731，2026-07-31 公测）
- 官方参照端点：`https://api.deepseek.com`（官方 DeepSeek API）

## 1. 配置事实（已核实）

- Codex 助手当前配置：`model = deepseek-v4-flash`，经 CC Switch 本机代理（127.0.0.1:15721）→ cloudprime 中转站（CC Switch provider "公司"，id 5694c95b...）。
- CC Switch 代理日志确认：本对话所有 Codex 请求均路由至该 provider，模型名 `deepseek-v4-flash`，全部 200 OK。
- 后端 CPQ 平台：数据库 `system_config.llm_config` 配置 `model = deepseek-v4-pro`（也是预览版），`.env` 兜底 `qwen3.7-plus`。
- 官方 DeepSeek key（CC Switch "DeepSeek" provider）实测返回 `402 Insufficient Balance`，余额为 0，暂无法做官方同题对比。

## 2. 指纹测试结果（全部走原始 OpenAI 兼容接口、无工具、纯推理）

## 3. 结论

- **高置信度**：cloudprime 中转站的 `deepseek-v4-flash` 实际提供的是知识截止早于 2026 年年中的旧模型（自报 DeepSeek-V3/V3.2 级别），并非官方 2026-07-31 发布的 DeepSeek-V4-Flash-0731。
- 即"挂着新模型名字的旧模型"，存在货不对板嫌疑。
- 由于官方 key 余额为 0，未能完成"官方 vs 中转站"同题对比；如需 100% 坐实，充值官方 key 后重跑 `backend/scripts/verify_llm_identity.py` 即可。

## 4. 建议

1. 保存本报告及测试日志，向 cloudprime 客服对质，要求出示上游接入凭证；若按 V4-Flash 收费，主张退款/补偿。

3. 维权/停用前，在 cloudprime 后台轮换该中转站持有的 key（`backend/.env` 与 CC Switch 中多处）。
4. 业务侧：CPQ 后端当前用的是 `deepseek-v4-pro` 预览版，Codex 用的是该中转站 `deepseek-v4-flash`；重要场景建议切官方直连或可信聚合商（CC Switch 中已有官方 DeepSeek / SiliconFlow 配置）。

## 7. 单 token 行为指纹法（论文方法，arXiv:2607.10252）与同协议对照（补充）

方法：采集 8 单元 × 25 样本的单 token 输出分布（随机数/颜色/动物/字母/掷硬币，温度 1.0，关闭思考），按论文方法计算 Jensen-Shannon 距离（JSD）。基线：同模型 ≈0.14，同模型不同供应商 ≈0.227，不同模型 ≈0.463；阈值 match≤0.25 / uncertain≤0.35 / mismatch。

| 对比对 | JSD | 判定 |
|---|---|---|
| 中转站 deepseek-v4-flash vs SiliconFlow DeepSeek-V4-Flash | 0.245 | match（临界） |
| 中转站 glm-5.2 vs SiliconFlow GLM-5.2 | 0.096 | match（强） |
| 中转站 glm-5.2 vs 论文参考 z-ai/glm-4.5 | 0.197 | match |
| 中转站 deepseek-v4-flash vs 论文参考 deepseek-chat 等 11 个 | 0.37-0.51 | mismatch |
| 中转站 deepseek-v4-pro vs SiliconFlow DeepSeek-V4-Pro | 0.456 | mismatch |
| 自洽性 splitHalf：glm-5.2=0.148（稳），flash=0.286，pro=0.338（不稳） | — | pro 疑似多后端 |

关键交叉验证：SiliconFlow（主流聚合商）的 deepseek-ai/DeepSeek-V4-Flash 与 zai-org/GLM-5.2 同样通过不了官方版本知识探针——自报 DeepSeek-V3、声称 V4-Flash 于 2025-04-24 公测（官方实为 2026-07-31）、不知道 2026 世界杯结果、不知道 GLM-5.2 存在（知识截止约 2025 年中）。

## 8. 结论修正（重要，力求公平）

1. **指纹层面**：中转站与 SiliconFlow 提供的同名别名行为一致（flash JSD 0.245、glm-5.2 JSD 0.096），因此**没有充分证据表明 cloudprime 单独"换模型"**——它和主流聚合商 SiliconFlow 提供的是同一批模型。
2. **版本真实性层面**：所有被测端点（中转站、SiliconFlow）的 "deepseek-v4-flash"/"glm-5.2" 别名都过不了官方 2026 版本的"知识截止"测试，疑似整条供应链（含 SiliconFlow）提供的别名都不是官方 2026-07-31 的 V4-Flash-0731 / 官方 GLM-5.2，而是知识截止约 2025 年的旧模型。
3. **唯一无争议的金标准**：官方 key 充值后，①官方直连跑同套知识探针；②官方直连采指纹与中转站/硅基流动同协议对比。在此之前，"cloudprime 造假"的指控应降级为"所提供模型疑似非官方最新版，且与硅基流动行为一致，疑为供应链共性问题"。
