## **节点功能**

**结束节点**属于**基础节点**，标志着工作流运行的结束，支持在结束节点输出变量。

## **操作说明**

### **输出变量**

用于返回工作流运行后的结果。支持用户进行如下配置手动新增输出变量。

|   |   |
|---|---|
|**配置**|**说明**|
|变量名称|该变量的名称，只能包含字母、数字或下划线，并且以字母或下划线开头，必填|
|变量描述|该变量的说明信息，非必填|
|数据来源|该变量的数据来源，支持"引用""输入"两种选项。"引用"可选择前序所有节点的输出变量，"输入"可手动填入固定值|
|变量类型|该变量的数据类型，不可选择，默认为"引用"的变量类型或"输入"的 string 类型|

## **智能体应用示例**

在引用工作流时（例如通过"工作流节点"引用，或者通过"循环节点"引用），在被引用的工作流运行结束后，返回"结束节点"中的输出变量，主工作流可以接收并使用这些变量。具体示例见"开始节点"应用示例。

## **常见问题**

**为什么结束节点没有输出答案？**

需要在结束节点之前配置可以输出答案的节点，例如：回复节点、大模型知识回答节点。

**新元器的结束节点和老元器有什么不同？**

新元器新增的回复节点和结束节点，主要目的是更清晰地区分这两种节点的功能。回复节点用于输出回复内容。新元器的结束节点不再用于回复内容，仅用于接受输出变量。这样做的原因是，我们发现一个工作流中经常需要在运行中输出中间结果，这就需要工作流可以添加多个回复节点。但老元器的回复和结束节点是同一个节点且仅有一个。因此，在新元器，我们把回复节点和结束节点做了拆分。
