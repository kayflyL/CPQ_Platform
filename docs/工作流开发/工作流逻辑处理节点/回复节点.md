## **节点功能**

**回复节点**属于**基础节点**，用于将工作流的运行结果输出给用户。

## **操作说明**

### **输入变量**

输入变量仅在该节点内部生效，不能跨节点使用。支持最多添加50个输入变量，满足多输入变量场景需要。点击添加，进行如下配置添加输入变量。

|   |   |
|---|---|
|**配置**|**说明**|
|变量名称|该变量的名称，只能包含字母、数字或下划线，并且以字母或下划线开头，必填|
|变量描述|该变量的说明信息，非必填|
|数据来源|该变量的数据来源，支持"引用""输入"两种选项。"引用"可选择前序所有节点的输出变量，"输入"可手动填入固定值|
|变量类型|该变量的数据类型，不可选择，默认为"引用"的变量类型或"输入"的 string 类型|

### **回复内容**

表示工作流运行中回复给用户的内容，支持输入文字**、字体加粗**、**插入图片（包括引用工作流中产生的链接显示图片，例如微信支付二维码）、链接、上传视频、表情**。

### **输出变量**

默认包含回复给用户的内容以及运行时报错信息 Error（数据类型为 object，正常运行时该字段为空）。支持用户进行如下配置手动新增输出变量。

|   |   |
|---|---|
|**配置**|**说明**|
|变量名称|该变量的名称，只能包含字母、数字或下划线，并且以字母或下划线开头，必填|
|变量描述|该变量的说明信息，非必填|
|数据来源|该变量的数据来源，支持"引用""输入"两种选项。"引用"可选择前序所有节点的输出变量，"输入"可手动填入固定值|
|变量类型|该变量的数据类型，不可选择，默认为"引用"的变量类型或"输入"的 string 类型|

## **常见问题**

**结束节点和回复节点有什么区别？**

新元器新增的回复节点和结束节点，是老元器的结束回复节点调整而来，主要目的是更清晰地区分这两种节点的功能。回复节点支持在工作流运行中输出中间结果，一个工作流中可以添加多个回复节点；而结束节点汇总工作流完整运行后的结果并对外输出，一个工作流中仅能存在一个结束节点。
