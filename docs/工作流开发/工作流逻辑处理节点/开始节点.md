## **节点功能**

**开始节点**属于**基础节点**，用于标识工作流的启动，是整个工作流的入口。

## **操作说明**

### **系统变量**

系统变量是**工作流内的全局变量，在工作流的任意节点都可以引用**，默认无法更改。包括本轮对话内容、多轮对话中本轮对话改写结果、对话历史和当前时间。

### **API 参数**

**表示您在调用腾讯元器 API 时，通过 custom_variables 字段（该参数的使用详情请参考：**[API接口文档](https://yuanqi.tencent.com/guide/publish-agent-api-documentation)**）传入工作流的变量，在工作流中引用该变量执行后续业务逻辑。**

可自定义添加参数，通过"管理"进入 API 参数新建，支持填写默认值。

**使用场景：**

在"**员工差旅报销**"场景中，您可以在调用腾讯元器 API 时，将 userID（假设该字段表示员工ID）放入 custom_variables 字段中传入工作流。在工作流的开始节点的 API 参数中配置 userID 字段，该字段名称和数据类型与您在接口中传入的保持一致。工作流后续节点中您可以直接引用该变量。

在工作流运行时，系统会自动解析并使用 custom_variables 中的 userID 字段，运行工作流后续节点。

### **输入变量**

**表示腾讯元器系统在运行该工作流时所需要输入的变量，支持用户自定义。该变量主要用于工作流间的流转（例如主工作流中的变量传递到子工作流，此时子工作流的开始节点需要通过输入变量接收）。**

|   |   |
|---|---|
|**配置**|**说明**|
|变量名称|变量的名称|
|默认值|输入变量初始默认值|
|变量描述|变量的描述信息，帮助模型理解变量的含义|
|变量类型|变量的数据类型，支持 string、int、float、bool、object、array<string>、array<int>、array<float>、array<bool>、array<object>，文档格式支持file、document、image、audio。其中文档格式变量仅支持文档链接，非原文件|
|必填|变量是否必填，启动该流程时是否必须输入的该变量|

## **智能体应用示例**

父工作流"社媒分析一级"需要调用子工作流"社媒分析二三级"。子工作流的开始节点设置接受内部输入内容或传入文件的输入变量。

子工作流结束节点设置：

父工作流的工作流节点，通过输入或引用前序节点的方式，将子工作流需要的输入变量传入。

父工作流内部调用的"社媒分析二三级"工作流运行结束，可以将输出变量传出，供父工作流使用。

运行过程中，将"社媒分析一级"父工作流中的"一级标签"和用户输入内容作为子工作流"社媒分析二三级"的输入。运行过程中，"社媒分析一级"父工作流中可以使用"社媒分析二三级"子工作流的输出。

## **常见问题**

**API 参数和输入变量有什么区别？**

API 参数是从"**外部**"系统传入到腾讯元器中的变量，而输入变量是腾讯元器"**内部**"流转的变量。
