## **怎么选模式**

**工作流**在2种应用模式下均可使用：**标准模式**、**单工作流模式**。那么两者之间的用法有什么不同呢？该怎么选呢？（操作详见：[进阶：如何选择应用模式](https://yuanqi.tencent.com/guide/agent-build-choose-mode)）

其实核心就回答2个问题：

1、是不是一个工作流就可以解决全部问题？

2、是否强制用户进入工作流？

### 1、是不是一个工作流就可以解决全部问题？

如果答案为"是"，请跳到问题2。

如果答案为"否"，请选**标准模式**，因为只有标准模式支持多工作流。

﻿

### 2、是否要求100%进入工作流？

**前置条件**：问题1的答案为"是"。

如果答案为"是"，请选**单工作流模式**。

**什么情况需要“100%进入工作流”？**

举个例子：智能体应用名为“**猪八戒勇闯盘丝洞**”，有固定的故事情节，哪怕用户上来就问：天气怎样。也会直接回复故事的开场设定。那么这时候就需要用单工作流模式。

﻿

## 两种模式的工作链路

|   |   |   |
|---|---|---|
|模式|标准模式|单工作流模式|
|一句话区别|所有问题会经过一个无法干预的思考模型，判断要不要调用工作流，有概率进不去工作流|所有问题100%进工作流|
