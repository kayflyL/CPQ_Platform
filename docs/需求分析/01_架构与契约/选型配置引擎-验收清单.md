# 选型配置引擎 · 变动验收清单

> 2026-11-07。配套《选型配置引擎-设计方案》。前置:改了后端代码,**必须重启后端**(launch.json 无 --reload;uvicorn 有 multiprocessing 子进程,杀父进程后要找 spawn_main 的 python 一并杀)。数据现状:CPU 系列适配已填(过滤已生效),GPU/网卡/主板的适配与 Socket 未录(相关过滤暂不可验,录完自动亮)。

## 快速冒烟版(3 分钟,7 步)
1. 报价工作台新建方案,机型选 **ZS25V2-P** → CPU 卡下拉:只有 KH 系列,**AMD/Intel 一件都看不到**,头部有「已按机型过滤 N 件不兼容」黄字;
2. 机型换 **ES220 V3**(AMD)→ CPU 下拉反转,只剩 AMD/Intel 件;
3. 内存加两行不同型号 → 右栏「选型建议」出红色冲突;
4. 内存数量加到 24 以上 → 步进器钳住,不弹告警;
5. 保存 → 弹「保存前校验」列冲突;点「仍要保存」;再保存一次,弹窗显示「已有 1 次豁免留痕」;
6. /settings/engine(配置引擎) 治理面:规则卡出现「同类一致:内存/CPU/GPU 不混型号」(徽标「同」),编辑弹窗有「优先级」列,类型下拉多出同类一致/资源预算/候选排除;
7. 治理面把「同类一致」停用 → 回工作台混插不再报冲突;启用 → 冲突回来(改规则即时生效)。

## A. 报价工作台(主战场)

| # | 类型 | 操作 | 预期 |
|---|---|---|---|
| A1 | 视觉 | 打开任一方案 | 右栏新增「装配账本」卡:装机功耗条 + CPU/内存/盘位/GPU/电源 五行占用(used/max,未录上限显示 —) |
| A2 | 视觉 | 选定机型后展开任一 KP 类目卡 | 头部「N 个可选料号」旁出现黄色「已按机型过滤 N 件不兼容」;无过滤时不显示 |
| A3 | 功能 | 兆芯机型 → CPU 下拉 | 只显 KH 系列件;AMD/Intel 全部不出现(ZS25V2-P 实测:23 允许 / 12 被滤) |
| A4 | 功能 | 切换 AMD 机型 | CPU 下拉反转;数据已录的类目同样反转(GPU/网卡待录数据) |
| A5 | 功能 | 内存两行不同 PN | 「选型建议」红条:同类一致冲突,列出两个型号 |
| A6 | 功能 | 内存总数超 24 | 数量步进器直接钳到 24(max_dimm),不产生告警文案 |
| A7 | 功能 | 带 A5/A6 违规保存 | 弹「保存前校验 · N 项需要处理」逐条列出;「仍要保存」后方案记豁免;再保存弹窗显示「已有 N 次豁免留痕,将随方案保存」 |
| A8 | 功能 | 上传含 AMD CPU 的 Excel 到兆芯方案并保存 | 校验点名「CPU「AMD…」与当前机型不符(系列 兆芯 不适配);换兼容件或移除该行」——以前静默通过 |
| A9 | 功能 | 双 CPU 高 TDP(如 400W×2)| 账本功耗条变黄(>83%)/红(>100%);PSU 容量未录瓦数的机型容量侧显示 —(4 机型待录,录后生效) |
| A10 | 功能 | 治理面停用/改「NVMe 线缆」规则 per 值 | 工作台派生建议行数即时变(每盘一根→改值即变) |

## C. 公开向导(匿名,门户机型页)

| # | 类型 | 操作 | 预期 |
|---|---|---|---|
| C1 | 视觉 | 配置到有违规 | 右栏「规则结果」面板:必配/互斥/预算/钳制徽标 + 描述;摘要条徽标冲突红优先 |

## D. 治理面(/settings/engine(配置引擎))

| # | 类型 | 操作 | 预期 |
|---|---|---|---|
| D1 | 视觉 | 规则列表 | 「同类一致:内存/CPU/GPU 不混型号」单卡,徽标「同」;类型下拉含 同类一致/资源预算/候选排除 |
| D2 | 视觉 | 编辑任意规则 | 表单头部有「优先级」列(数值小者先判);同类一致表单=类目多选;资源预算=两侧字段+倍率+比较符;候选排除=目标类目+part.spec 谓词(含「无值」操作符) |
| D3 | 功能 | 新建一条资源预算规则(如 PSU 容量 ≥ 装机功耗 ×1.2)| 保存即生效,工作台账本旁立即出现该约束的校验(数据齐才判,缺数据跳过不误报) |
| D4 | 功能 | 删除/停用规则 | 三配置面下一次操作即生效,无缓存残留 |

## F. 明确不变的部分(防误会)

- 机型目录页、商机详情、需求分析工作流、AI 同事:外观与行为零变化;
- 旧报价单打开:数据照旧,引擎对旧方案照跑校验(有违规会在保存时点名,不影响展示);
- 价格:账本/过滤零价格,价格面照旧权限控制。
