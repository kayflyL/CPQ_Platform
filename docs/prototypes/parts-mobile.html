> 最后更新：2026-09-19 · 原型稿 V2（按定调重画：首页磁贴化 + 搜索置顶 + 二级分类列表）

信息架构改为两级驾驶舱：首页 = 磁贴（大搜索框置顶 + 统计磁贴 2×2 + 分类磁贴网格，具体配件不再出现在首页）； 点分类磁贴 → 二级列表页（该分类的筛选 + 卡流 + 分页，筛选侧栏仍在左抽屉）。搜索进首页且搜全库， 搜完落「全部 + 关键词」列表。桌面版零改动，两级切换为组件内视图（手机端专属）。 四张手机框：A 首页磁贴 / B 二级分类列表 / C 左抽屉·筛选 / D 对比与分期。

V2 相对 V1 的变化（按定调）

  • 首页磁贴化：分类从 chips 变磁贴网格（彩点 + 名称 + 数量主字，层级靠字号字重），模仿商机线索页驾驶舱；具体配件卡片移出首页。
  • 搜索置顶：大搜索框第一触点、全库范围；二级内另有分类内搜索。
  • 两级导航：首页 → 分类列表，返回键回首页；替代 V1 的 chips 平铺扁平结构。
  • 保留：筛选左抽屉、已选 chips、统计磁贴、表格视图隐藏、桌面零改动。

分期落地

P1两级容器（≤768px）：mobileView 状态 + 首页磁贴（搜索框/统计 2×2/分类网格/尾卡）+ 二级列表页（返回/搜索/筛选行/卡流/分页）+ 筛选左抽屉；桌面零改动。
P2联动细节：磁贴按压反馈；「其余 N 类」贴展开为全分类清单；二级返回时保留筛选与页码状态。
P3打磨（可选）：搜索历史/热门分类快捷词；磁贴长按快捷（编辑分类）；卡流无限滚动。

代价与取舍

  • 进清单多一步：首页→磁贴→列表两级——换来首页轻、搜索直达、层级清晰；高频「全库搜」场景一步直达补平。
  • 统计与清单分离：库级概览只在首页——二级专注清单，不重复渲染。
  • 组件内视图 vs 真路由：选组件内状态（不新增路由）——桌面仍是单页，避免为手机端拆双路由的工程量；代价是浏览器返回键不回首页（页内返回键承担，P2 可监听 popstate 补齐）。

与全站手机版语言的一致性

  • 首页磁贴：与商机线索页驾驶舱磁贴同一语言（统计 + 实体网格 + 色条识别）。
  • 二级列表：筛选左抽屉 + 已选 chips + 卡流，同电商范式。
  • 五页一套心智：线索页 / 详情页 / 配置向导 / 报价工作台 / 配件页——按页面类型取用「工作台双抽屉」或「列表两级」两种范式。
