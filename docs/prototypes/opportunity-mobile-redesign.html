商机线索 · 手机模式重设计

> 最后更新：2026-09-19 · 原型稿（仅视觉示意，非实现）

本稿回应三件事：① KPI 卡（总商机数 / 总配置数…）手机端沉底 → 移到页首； ② 「商机列表」磁贴点击 → 右侧滑出完整列表抽屉，可收起；③ 全局新增移动端底部导航栏（替代现有汉堡全屏菜单）。 四张手机框从左到右：新首页 / 列表抽屉 / 「更多」面板 / 底栏规范标注。

问题诊断（现状）

  • KPI 沉底根因：OpportunityList.vue 的 DOM 顺序是 图表区(.charts-panel) 在前、表格区(.table-side，内含 KPI 条) 在后；手机端 .main-split 变纵向排列后，KPI 卡被整体推到图表之后 —— 不是 KPI「掉下去」，是它天生住在右栏里。
  • 列表埋两屏深：手机端「商机列表」磁贴目前是 scrollIntoView 平滑滚到下方表格，宽表 + 筛选行被图表磁贴压在第二三屏。
  • 导航高位难够：手机端导航 = 左上角汉堡 → 全屏浮层；单手持机时拇指够不着，也看不到自己在哪。

分期落地

P1本页两改（仅手机分支，桌面零改动）：① 手机端图表区上方渲染 KPI 2×2（v-if isMobile，数据同 summary.kpi），原 .table-side 里的 KPI 条手机端隐藏；② 列表磁贴 → a-drawer 右滑出完整列表（卡式行 + 粘性筛选 + 分页吸底），手机端内联表格下线。
P2全局底栏（DefaultLayout）：5 槽 = topItems 权限过滤后前 4 + 更多；更多 = 底部 sheet（剩余页 + 设置组 + 用户卡）；汉堡与全屏浮层退役；布局层加底部占位（底栏高 + safe-area），对齐顶部 scroll-clearance 让位模式。
P3打磨（可选）：抽屉右滑手势关闭；列表行左滑快捷操作（改状态/重命名）；新建商机 FAB 化；底栏滚动时微缩动画。

风险与兼容

  • 共用组件不动：OpportunityTable 被门户工作台四子页复用，抽屉方案只换商机线索页手机端的容器与行样式，组件本身不改（或抽屉 P1 先复用 OpportunityTable + 横向滚动，卡式行 P3 再换）。
  • 状态恢复：列表筛选/页码已走 sessionStorage(LIST_STATE)，抽屉开合态加一个字段即可随详情页返回恢复。
  • 主题与暗色：原型为浅色示意；实现走 --cpq-* 玻璃 token，跟随现有明暗主题，不引入新色值硬编码。
  • 登录页/原型页：底栏只在 DefaultLayout 内渲染，登录页不受影响。
