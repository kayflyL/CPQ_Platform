服务器配置页 · 手机版优化方案

> 最后更新：2026-09-19 · 原型稿（仅视觉示意，非实现；页面为固定暗色链路，原型按暗色画）

桌面三栏 = 左：配置卡输入流（机箱 + KP 卡）/ 中：服务器图纸解剖图 / 右：配置结果（规则 · 电源 · 性能）。 手机现状是「图纸占顶 → 配置卡 → 结果沉底」，要滚过大图才能配、配完看不到反馈。 方案延续全站语言：主屏 = 配置卡流（输入主场）；左抽屉 = 服务器图纸；右抽屉 = 配置结果；底部 sticky 摘要条常驻电源/规则/性能关键值。 四张手机框：A 主屏 / B 左抽屉·图纸 / C 右抽屉·配置结果 / D 对比与分期。

现状诊断

  • 图纸占顶：≤960 断点下 grid-areas 把 map 排第一位，图纸 min-height 440px 挡在首屏——但配置操作不需要先看图。
  • 结果沉底：电源/规则/性能排在配置卡之后，改一颗 CPU 要滚到页尾才知道功率够不够。
  • 步骤条弱化：sc-steps 横向滚动，点击只是 scrollIntoView，长页里定位价值低。
  • 桌面无恙：三栏各司其职（输入/可视化/输出），只有手机端需要重排。

分期落地

P1容器重构（≤768px）：图纸 → 左抽屉、配置结果 → 右抽屉、新增底部 sticky 摘要条（⚡电源 + ⚠规则数 + 📐入口 + 完整结果）；配置卡流保持现状；桌面三栏零改动。
P2联动细节：摘要条规则红点区分 severity（冲突红/追加黄）；L6 细配弹窗与抽屉互斥；摘要条电源值变化微动画。
P3打磨（可选）：抽屉内图纸双指缩放；规格书 overlay 手机端排版专项；配卡完成度进度环（x/N 类别已配）。

代价与取舍

  • 看图多一步：边配边盯图的工作流会多开抽屉——但摘要条常驻 + 抽屉不销毁（二次打开即时），且「配完核对」场景一次开抽屉就够。
  • 完整结果多一步：规则/功率全量收进抽屉——摘要条已把最高频的「建议电源 + 命中数」常驻，日常不需要开。
  • 收获：首屏从「看图」变成「动手」，配置反馈从页尾搬到拇指区；与线索页/详情页形成全站统一的手机版三段式。

与全站手机版语言的一致性

  • 线索页：中间驾驶舱 + 右抽屉列表 + 底栏。
  • 详情页：中间工作台 + 左抽屉流程轨道 + 右抽屉动态 + sticky 动作条。
  • 本页：中间配置卡 + 左抽屉图纸 + 右抽屉结果 + sticky 摘要条 —— 三页同构，用户学会一次就会用所有页。
