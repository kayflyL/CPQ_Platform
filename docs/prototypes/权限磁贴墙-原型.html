角色对比（拍板项 · 可二期）

业务（6 项）

✓ 商机子页面 · 服务器 · 配件页
✓ 发起/提交需求单 · 修改商机状态
✓ 新建商机 ← 技术没有
✗ 方案附件 · 提交/退回方案

技术支持工程师（7 项）

✓ 商机子页面 · 服务器 · 配件页
✓ 修改商机状态
✓ 方案附件 · 提交/退回方案 ← 业务没有
✗ 新建商机
结论：技术 = 业务 ＋ 方案配置三操作 ＋ 方案存档区 − 新建商机

设计标注（v3，确认后即为规格）

01层优先三带（本版核心修正）：一带页面磁贴只放开关不放细节；二带字段键全系统仅 6 个天然一屏；三带操作按域折叠、默认收起。v1 的「域磁贴内嵌全部芯片」废弃——那是字密的根因。
02密度对策：一带每贴 ≤3 行；二带每卡 2 行；三带收起时每域 1 行。全页首屏无小字块。
03保留：底版+增量（压成上下文条一行）、已授权成员 Tab、⋯菜单、详情抽屉、危险区。列表视图与网格视图都删除——三带层取代两者，不留并列模式。
04机密键（价格三键）：「机密」徽 + 勾开二次确认（含影响人数）；后端 deps 与前端 store 的 fail-closed 语义不受本改版影响。
05生效语义：「保存后 · N 名成员需刷新生效」替代「即时生效」。
06视觉：tokens 全量引用；无左侧彩条；域色只做 8px 圆点；磁贴 hover 浮 2px；开关=圆角胶囊（组件化后进 UI 库）。
07两 Tab 打通：角色卡显示成员头像；用户表角色列点击直达该角色（随实现一并做）。
08反 AI 味清单自查（impeccable.style/slop 59 条）：标题去破折号；卡片边框与投影二选一（玻璃卡留投影、清单行只有分隔线）；三带去外层嵌套卡；字段带改清单不做卡片墙；去悬浮位移动效；域色圆点保留（应用既有语言）。
