商机线索 · 手机版双抽屉方案（V2）

> 最后更新：2026-09-19 · 原型稿（仅视觉示意，非实现）

思路：首页收成「轻枢纽」——KPI + 周期 + 两大入口；左侧图表分析 → 左抽屉、商机列表 → 右抽屉， 与桌面「左图表 / 右列表」的空间心智一一对应。右抽屉上一轮已上线（PC 同款表格，直接沿用）， 本版新增 = 首页枢纽化 + 左抽屉。四张手机框：A 首页枢纽 / B 左抽屉 / C 右抽屉（已上线）/ D 对比与分期。

信息架构变化

  • 首页（枢纽）：顶栏 + KPI 2×2 + 周期 chips + 双入口卡（图表分析 / 商机列表·计数）+ 趋势快览（可选）。一屏收口，拇指可达。
  • 左抽屉（图表分析）：placement=left、宽 94%、全高；周期 chips（与首页同源）+ 趋势 / 结构分布 / 业务排行 / 线索转化；ECharts 懒挂载改由抽屉首开触发。
  • 右抽屉（商机列表）：上一轮已上线，原样沿用（PC 同款表格 + 全量筛选 + 跳详情收抽屉/返回恢复）。
  • 退役：首页图表磁贴流与「商机列表」磁贴（入口卡替代）；列表磁贴的 open-list-drawer 事件改由入口卡触发。

分期落地

P1首页枢纽化： OpportunityCharts 与磁贴移出手机端首页流；新增双入口卡 + 快览磁贴；左抽屉容器 + OpportunityCharts 挂入（isMobile 磁贴布局保留）。
P2联动收尾： 抽屉内周期 chips 与首页同源；下钻 → 收左抽屉 + KPI 已筛选提示（drill 机制现成）；LIST_STATE 增加 charts_drawer 恢复；两抽屉互斥。
P3打磨（可选）： 边缘滑动手势开抽屉；快览磁贴点击直接开左抽屉并定位趋势图。

代价与取舍（我的看法）

  • 多一步点击：看完整图表要从「直接滚」变成「点开左抽屉」——用首页快览磁贴补偿日常扫一眼的需求，重分析场景进抽屉反而更舒展。
  • ECharts 在抽屉里初始化：首次打开有一次渲染成本，沿用 chartsReady 懒加载 + autoresize 可控；抽屉关闭不销毁，二次打开即时。
  • 两抽屉不同时开：共享一个 openDrawer: null | 'charts' | 'list' 状态，蒙层天然互斥。
  • 收获：手机版与桌面共享同一套「左图右表」心智；首页从最长页变成最短页之一。
