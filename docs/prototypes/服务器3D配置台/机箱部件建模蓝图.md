# 机箱部件建模蓝图（机框 + 上盖 · 闸1 · 待确认）

> 参照：**本产品**渲染图 7 视角（`refs/` 内 前视/后视/俯视-带盖/俯视图-无盖/侧视/右侧/左侧，来自 ZSA240 V2 4U 样机渲染图）；整体尺寸级别参照 ZTE R6530 G3 拆解页（GLB 公网不可达，公开渠道也查不到毫米级尺寸，仅确认 4U 机架形态与同系列 2U=830mm 深的量级）。
> **尺寸结论**：宽 448mm（19" 标准机架，不含耳）与高 178mm（4U）是行业标准，**锁定**；深度官方未公开，按渲染比例初值 **650mm 标「待核对」**，拿到实件数字即替换。

## 1. 目标与范围

- 部件库新增两个部件：**机框**（part_type='chassis_frame'）与 **上盖**（part_type='top_cover'）。
- 机框=壳体骨架+前面板总成（开孔处透空）；上盖=两片式拉丝铝盖板。两者可独立查看/爆炸，将来整机装配蓝图时机框内腔挂 CPU/风扇墙/盘位等部件，上盖扣合。
- **不动 machine.ts**：整机配置台的 stylized 机型保持现状，机框/上盖是部件库独立件（防回归）。

## 2. 尺寸依据（2026-11-04 量图管线实测,替代初版估算）

**方法**：前/侧/俯三视图构成正交三视图组，用已知锚点（宽 482.6 含耳 / 448 裸宽、高 178=4U）对每张图解出 px/mm 标定，同一尺寸多视图交叉验证（差 <2% 采信）。

| 项 | 实测值 | 依据 |
|---|---|---|
| 宽 | **448mm**（裸） / **482.6mm**（含挂耳） | 标准+前视图交叉验证（高178标定→宽479✓） |
| 高 | **178mm**（4U 标准） | 锁定 |
| **深** | **≈835mm**（待核对±10） | 三视图交叉：带盖俯视831 / 无盖俯视838 / 侧视850-899(含凸出)，与 ZTE 同系列 830mm 量级吻合；**初版估算 650 已作废** |
| 盘位列距 | **101mm**（4列,蓝把手条中心 122/224/325/425mm） | 前视图蓝色像素定位实测 |
| 上盖分片 | 主盖约 78% 宽 + 左窄盖约 15% | 俯视图-带盖比例 |

**闸2 门禁同步升级**：每轮 pass 用正交相机按同标定渲染同视角，与参考 PNG 叠加对比（轮廓 IoU≥0.9 为块头门禁）——"像不像"变成"对没对齐"。

## 3. 结构分层与拆解

### 机框 chassis_frame

| 部件 | 内容 |
|---|---|
| 底板+左右侧板 | 拉丝铝银色，侧板带折页提手×2（前后各一，银色扣手）+黄色警示标签形 |
| 后横梁+挂耳 | 黑色机架耳×2（后角），后板开 PCIe 挡板长条区/电源开孔区（透空） |
| 前面板总成（黑） | 分四区：左控制面板（按钮/灯位凸起）、六角网孔通风区（上 60%）、12 盘位开孔区（4列×3行，透空）、右 IO 柱（VGA/USB 开孔） |
| 内腔 | 透空（无盖俯视内部可见——将来装配蓝图挂载点） |

### 上盖 top_cover（细节按 ZTE 真实盖板截图，用户 2026-11-04 提供）

| 部件 | 内容 |
|---|---|
| 主盖板 | 拉丝铝，约 78% 宽；**左侧蓝色箭头标**（胶囊+白箭头，指示开盖推动方向）+ **右侧蓝色圆环旋钮锁扣**（环+白芯）+ 沉头螺丝×4 + 前脸缘两条黄色警示标签 |
| 左窄盖板 | 拉丝铝，盖控制面板区；**白底配置标签**（橙红图形条示意，无文字）+ 沉头螺丝×4 |
| 标签 | 黄色警示标签形（只做形状不写字） |

### 爆炸行为

- 上盖沿 **+Y 垂直升起**（分片先后微差：窄盖先起、主盖后起，教学语义=先松窄盖卡扣）——部件页内可直接看到"开盖"。
- 机框本体不动（它是装配基座）。提手/扣手做小幅外翻动画可选项（P3 评估，默认不做）。

## 4. 材质方案（全程序化）

- 拉丝铝：MeshPhysicalMaterial + **anisotropy**（各向异性拉丝）或程序化 roughnessMap（CanvasTexture 细条纹），metalness 0.85 / roughness 0.4，envMapIntensity 0.5——**顶视中心亮度 <200 验收**（闸4 教训：大面积银色板+metalness 1 = 顶视炸白重灾区，入参直接封顶）
- 前面板黑漆：roughness 0.6，metalness 0.2
- 蓝扣手：宝蓝 #2b5cb8 半光
- 警示标签：黄底三角形形状（CanvasTexture 画三角形轮廓，无文字）
- 双主题：dark=原型色；light=铝板提亮、黑面板提灰，切一遍不糊白

// 契约同 cpu.ts/fan.ts;尺寸入参 { depth?: 650 }
// PART_INFO 语义键: frame侧板/baseplate底板/frontbezel前面板/ear挂耳/handle提手/

- 迁移种子两行（kind='part'）：「机框」「上盖」；管理页部件库自动出现
- 上盖单独一个部件页的价值：开盖动画=培训「如何拆上盖」的第一课

## 6. 知识卡语义（培训预留）

- 机框=承载骨架，19" 机架安装，挂耳承重
- 上盖=两片式，蓝扣手按下后推即可开盖（免螺丝工具化设计）
- 网孔区=风扇墙进风位；盘位区=12×3.5" 前置热插拔
