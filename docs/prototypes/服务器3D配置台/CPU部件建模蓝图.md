> **可视版**：[CPU部件建模蓝图-可视版.html](CPU部件建模蓝图-可视版.html)——可交互示意台（形态族切换/爆炸滑块/翻转看触点阵），文字版以本文档为准。

## 1. 目标与范围

- 3D模型管理新增「部件模型」类型：CPU 先行，后续 GPU/DIMM/盘位/PSU/风扇/机箱同法复制。
- 部件模型页要求：**能看（四视角）、能爆炸（分层拆解）、能点选（部件级标注）**；部件将来按装配蓝图组合成整机（比现在的 machine.ts 更精细）。
- 路线：**纯程序化建模**（零模型文件），素材仅作视觉参照。

## 2. 首个型号选择（已定）

主型号 = **AMD EPYC 9004（SP5 封装）**，第二变体 = **兆芯 KH-40000**。
理由：服务器属性最强（EPYC 即 ESA240 V3 的平台 CPU）；官方渲染图质量高、结构层次清晰；两家形态差异大（掀盖式chiplet vs 单die银盖），一套参数化族能覆盖两种形态，验证工厂接口的通用性。

## 3. 结构分层与拆解层级

### EPYC 9004（SP5，掀盖+chiplet 形态）

| 层 | 内容 | 拆解行为 |
|---|---|---|
| L0 | 整体装配态 | 默认 |
| L1 | IHS 顶盖（镀镍铜盖，四边缺口式边缘，激光刻字品牌字，角部定位缺口） | 抬起+悬停露出内部 |
| L2 | Chiplets：CCD ×N 环绕中央 IOD 布置（9004 最多 12 CCD；具体颗数参数化） | IHS 抬起后可见；爆炸态三层分离 |
| L3 | 封装基板（蓝绿哑光，底面 LGA 触点阵金色焊盘，角部金三角 pin1 标记） | 爆炸态下沉 |
| L4 | 顶部 SMD 电容排（IHS 开窗沿口一圈小电容块，instanced） | 随基板层 |

爆炸逻辑：IHS 上浮、chiplets 层原位、基板下沉——**沿轴向分层**，不做径向散射。

### 兆芯 KH-40000（单 die 银盖形态，第二变体族）

| 层 | 内容 |
|---|---|
| L1 | 银色方形 IHS（刻字品牌字「兆芯」） |
| L2 | 单片大 die（绿色基板裸 die 直露型，参见图中背景历代产品） |
| L3 | 绿色封装基板 + 触点阵 |

尺寸依据：**待核对**——SP5 封装约 75×75mm、LGA-4094；KH-40000 封装尺寸官方未公开，先按与 SP5 同数量级建模，你若有实件/规格书给个数字我再替换。不发明"看起来像"的假精确值。

## 4. 材质与细节方案（全程序化）

- IHS：高 metalness 低 roughness 镀镍质感；**激光刻字用 CanvasTexture 程序化生成，只刻品牌字（AMD / 兆芯），不出现具体型号**（2026-11-03 用户定调）
- Die：深色基底 + 微彩反光（物理材质轻微 iridescence），CCD/IOD 用几何位置区分，不画电路纹理
- 基板：哑光蓝绿；底面触点阵 = InstancedMesh 金色小焊盘（数千实例，性能无忧）
- 电容：InstancedMesh 小长方体沿边排布
- 金三角：基板角部小金色三角贴片
- 双主题：跟随现有 server3d THEMES 机制（浅色下 IHS 高光要压曝光，防糊白）

## 5. 工厂接口（部件库契约）

```ts
// frontend/src/server3d/parts/cpu.ts
createCpuModel(spec: CpuSpec): Group
// CpuSpec = { family: 'sp5' | 'kh', label: string, ccds?: number }
// 契约: 根 Group userData.part='cpu' + userData.explode 层级表;
// 语义层: 每子件 userData: { key:'ihs'|'ccd'|'iod'|'pcb'|'caps', name, spec, desc }
//   → 与现有 PART_INFO 悬浮标注同一套渲染,为培训知识卡预留(knowledge 字段后续加)
```

尺寸单位与整机一致（整机蓝本的坐标契约不变），保证将来 `整机蓝图引用部件工厂` 时零改造。

## 6. 管理界面扩展（闸3 范围，先定形状）

- `l6.server_3d_models` 加列 `kind text default 'machine'`（'machine' | 'part'）+ `part_type text`（'cpu'|'gpu'|...），迁移 SQL 一份，旧数据零影响
- 目录页：卡片按 kind 分组展示（整机 / 部件库）
- 模型页：ServerStage3D 已有四视角/爆炸/悬浮标注，部件直接复用；爆炸行为由部件的 explode 层级表驱动（轴向分层），与整机的中心缩放爆炸并存
- 新增入口：部件仍由代码/种子产出（沿用"删除假入口"定调），不做网页新建

## 7. 闸2 分pass 计划（每 pass 出对照截图，你确认后进下一 pass）

| pass | 内容 | 验收点 |
|---|---|---|
| P1 块头 | 俯视轮廓+比例+圆角缺口（无细节无材质） | 正方形比例、IHS 占比、缺口位置 |
| P2 结构 | IHS/基板/chiplets 分层、电容排布位 | 分层关系对、层次读得出来 |
| P3 细节 | 刻字、金三角、触点阵、die 布点 | 刻字可读、触点阵密度合理 |
| P4 材质+灯光 | 镀镍质感、双主题、最终四视角成片 | 与参考图对照整体观感 |

对照基准：refs/ 下两张参考图 + 渲染截图并排。工具链：img2threejs（pass 门控）+ Playwright 截图，产物放 `teardown-out` 同级的系统临时目录，仓库只收最终通过的代码。
