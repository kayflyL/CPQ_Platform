报价工作台 · 手机版优化方案

> 最后更新：2026-09-19 · 原型稿（仅视觉示意，非实现）

桌面结构 = 顶部多配置 Tab + 三栏（左：BOM 固化快照 / 中：核心编辑 / 右：定价与利润）+ 底部动作条（返回 · 模板 · 预览 · 保存）， 当前无任何手机适配。方案延续全站语言：主屏 = 中栏编辑区；左抽屉 = BOM 对照快照；右抽屉 = 定价与利润（含预览导出）；底部 sticky 摘要条 = 含税总价 + 毛利率 + 保存。 四张手机框：A 主屏 / B 左抽屉·BOM 对照 / C 右抽屉·定价 / D 对比与分期。

现状诊断

  • 零适配：Workspace.vue 无任何 ≤768 断点，三栏 + 顶部 cfg-bar + 底部动作条在 375px 下全部挤压变形，行内编辑基本不可点。
  • 三栏分工本就清晰：左=只读对照、中=编辑、右=结果输出——与手机版「主屏+双抽屉」天然同构，重排成本低。
  • 保存/预览沉底：底部动作条含返回/模板选择/预览/保存四个动作，挤压后误触风险高。

分期落地

P1容器重构（≤768px）：cfg-bar 横滑瘦身 + 返回并入；左抽屉（BOM 快照）+ 右抽屉（定价利润 + 预览导出）+ 底部摘要条（总价/毛利/保存）；KP 表横向滚动沿用；桌面三栏零改动。
P2联动细节：摘要条毛利告警色（低于门槛琥珀提示，对齐 fin-card 告警策略）；备选模式方案对比入口进摘要条；两抽屉互斥收尾。
P3打磨（可选）：KP 行卡片化（替代横滚表）；维保/系统软件段的移动端表单优化；保存成功后的回执动效。

代价与取舍

  • 看价格多一步：完整定价（税率/汇率/方案对比）进抽屉——摘要条已把「总价 + 毛利率」两个最高频值常驻。
  • 预览/导出收进抽屉：动作条退役——保存高频常驻摘要条，预览/导出与定价同属输出链顺路。
  • KP 宽表横向滚动：5 列表格 375px 放不下，P1 横滚保住「能编辑」，P3 卡片化再升级——与详情页 BOM 表同一取舍。

与全站手机版语言的一致性

  • 线索页：中间驾驶舱 + 右抽屉列表 + 底栏。
  • 详情页：中间工作台 + 左抽屉流程轨道 + 右抽屉动态 + sticky 动作条。
  • 配置向导：中间配置卡 + 左抽屉图纸 + 右抽屉结果 + sticky 摘要条。
  • 本页：中间编辑区 + 左抽屉 BOM 对照 + 右抽屉定价 + sticky 摘要条（总价/毛利/保存）——四页一套心智。
