共用底座的两条契约（实现规格，细节以本文为准并入 docs/交付工作流方案.md）：

① launch_form —— 声明式启动表单（配置者可编辑）

schema 存流配置 graph.launch_form（SkillStudio 左栏旁新增「启动表单」编辑器，即②页签）。 launcher「+」选中工作流 → 有 schema 渲染表单，无 schema 保持自由文本（机制按声明降级，零硬编码）。 提交 = 拼装结构化首条消息走现有装填链；不填表单直接说话，行为与现状完全一致。

"launch_form": { "fields": [ {"key": "attachment", "type": "file", "label": "成本表 / 方案表", "required": true}, {"key": "customer", "type": "text", "label": "客户名称", "required": true}, {"key": "sales", "type": "text", "label": "归属业务", "required": true, "default": "{当前用户姓名}"}, {"key": "margin", "type": "number", "label": "加价率 %"}, {"key": "view", "type": "select", "label": "出件视角", "options": ["scheme", "internal"]} ] }

② artifact —— 产物卡注册表（查看器=现成生产组件的薄容器）

消息 kind='artifact'，data={artifact_type, title, summary, refs}。refs 只存 id， 查看器按 ref 拉数后渲染现成生产组件——与人工操作所见完全一致，不写新表格： cost_sheet_parse → <CostSheetEditor :configs readonly>（组件自带只读模式）； quotation → <QuoteWorkbench :quotations :quotePriceVisible>（价格列显隐=组件现成 prop，面板折叠也有现成 props）。 权限在拉取时由 price_mask 体系生效。事务轮壳的 fact_guard 已零侵入拿到工具真实返回， 应用声明「工具成功 → 发哪张卡」（与 flags_from_facts 同模式）；前端 VIEWERS[artifact_type] 只做数据装配。

// 交付应用声明（配置） "artifact_rules": [ {"on": "import_cost_sheet.ok", "card": "cost_sheet_parse", "refs": ["opportunity_id", "sheet_id"]}, {"on": "submit_cost_sheet.ok", "card": "quotation", "refs": ["opportunity_id", "quotation_id"]}, {"on": "set_quote_margin.ok", "card": "quotation", "refs": ["opportunity_id", "quotation_id"]}, {"on": "share_quote.ok", "card": "share_link", "refs": ["share_path"]} ] // 前端注册表 const VIEWERS = { cost_sheet_parse: ParseViewer, quotation: QuoteViewer, share_link: LinkViewer } // 修正路径(解析错了):行级错=卡片切编辑模式(CostSheetEditor 非只读,保存走人工同接口); // 规则错=parse_overrides + sheet_id 原地重导(现成)。下载=现有视角化导出服务。 // 出件形态=分享链接(免登录token/可过期/可撤销)+文件归档商机附件;customer 视角永远走外发人审闸。
