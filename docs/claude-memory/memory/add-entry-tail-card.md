可增删区块的新增入口统一为「尾卡 ＋」范式：网格尾部放虚线「＋ 添加xx」卡（空态也常驻），行式区块用通栏虚线条；**不要**在区块标题行放「+ 添加」链接按钮。

**Why:** 用户 2026-08-17 在机型编辑页明确提出——他的操作习惯是"编辑完卡片后，后面还有一张写着加号的卡片，点它新增"；标题行里的链接按钮"怪、不符合操作习惯"。关联基准配置卡片网格是他认可的范本。

**How to apply:** 做任何编辑器/管理面的可增删列表（卡片网格或行式）时，新增入口一律尾卡/尾条；标题行只放批量型动作（如「填入六维预设」）。与 [[admin-card-pattern]] 配套。
