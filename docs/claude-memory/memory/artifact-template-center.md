产出物模板中心（2026-09-26 P0 落地，用户提案+原型 r2 批准后实现）：

- **架构定调**：工作流产出格式不再随机——模板=一等实体（rules.artifact_template，blocks 不透明 blob），**模板层零 AI**，AI 只填内容（answer 整段/章节槽位），渲染走确定性管线 blocks+数据→HTML→Playwright PDF。调研映射：PDF=jsreport 模式 / Excel=carbone 模式 / PPT=PPTAgent 模式；**Excel/PPT 门控为下期**，不做半成品。
- **09-29 架构收敛（用户「三跳太绕」定调后大白话方案获批；render 住址当天二次定调到输出节点，见下条）**：模板卸内容职责（不存统计天数/报告名，只按章节 key 引用槽位）；weekly_opportunity_report 更名「商机趋势报告」blocks 13 区块槽位化（七文本槽按章节 key/三图表/明细表，days 参数清空归运行时驱动）。运行时三桥：skill_turn_engine._deliver 组装 ctx["document_target"] → skill_node_runtime._render_file_artifacts：①split_answer_sections 按「一、{title}」拆 answer 进章节槽（容忍 # 前缀；标题行尾正文保留；漏节槽空自动隐藏）②_report_window 单源算封面口径（AI 复述的数据范围首行不进槽）③range_days→asset_params（含头含尾 N 天→N-1 对齐资产桶 start=today-days）。files[] 留痕 template_key+rendered_by。
- **图表资产同源**：资产=取数查询+option 构建器，住后端 chart_assets.py 单一权威源；编辑器预览（iframe srcdoc+防抖）与 PDF SSR 消费同一份。资产八件（cockpit.kpi/trend/dist/top_opps/model_trend/chassis_dist/sales_rank/profit）；口径=status NOT IN(ai_office,deleted)（曾把 316 条 AI 隐藏商机算进去被用户抓）。驾驶舱前端 option 未反向接入 registry（P1）。编辑器结构排序=⠿ 拖拽把手。
- **关键接线**：skill_node_runtime._render_file_artifacts 读 ctx["document_target"]（template_key 失败回退 legacy reportlab 不挡交付）；echarts.min.js 在 backend/app/static/vendor/ + 免鉴权 /api/artifact-templates/echarts.js；管理面 nav 'artifacts'（canManage 档）。
- **09-29 二次定调（呈现方式统一归输出节点，原型批准后实施+自查与原型一致）**：推翻「render 住目标层」——**内容（报告名/章节/数据范围）归目标层文档卡，呈现方式（出不出文件）归输出节点 config.render**。输出节点统一「呈现方式」四卡：随流程呈现（默认=零配置不出文件，nativeDesc 按 output_kind 说「落库后在哪儿看」）/ PDF（选中展开模板下拉+三态对接提示）/ Excel（置灰下期，副文案「复用『设置·导出模板』商务导出管线」）/ PPT（置灰下期）。render={enabled,format,template_key} 仅选 PDF 才写；闸门=`render.enabled is not True` 不出文件（None≠False 坑）。TargetLayerModal 回纯内容（save 剥存量 render）。迁移 fix_output_render_20260929.py 反向搬家（agent 卡 render→output config）。
- **09-29 结构化默认排版**：无文档卡的流（需求分析 bom_scheme_draft）也能出文件——`_render_structured_default` 按 payload 值形状自动组 blocks：dict→`fields` 区块（嵌套扁平化两列表）、list[dict]→`table` source=payload（行键并集动态列）；`_CELL_LABELS` 镜像 compose 列契约（part_category→Catalogue/catalogue→Configuration Description/qty→Quantity），ext 字段键不发明中文标签。files 留痕 template_key=default_layout+rendered_by=output_node。
- **坑**：①「需求原文」document 插头（input 节点、无 sections）会被误认成报告文档卡——前后端同款过滤：kind=document 且 sections 非空才算；②输出节点自带产物插头（方案配置卡 table）会让抽屉走目标层分支不渲染输出表单——模板 v-if 加 `activeNodeType !== 'output'`；③ output_kind 被 skillOutputKind 契约锁定为 'plans'（label「方案 / BOM」），OUT_NATIVE_DESC 须含 plans 键。
- **09-27 右栏可交互化四件**（用户「右侧栏只能看」定调）：①资产 params_schema+resolve_asset_data 通用 clamp ②预览点击反选（postMessage 双向 atc-select/atc-highlight/atc-height）③契约行点击定位区块④iframe 高度自适应+A4 分页参考虚线。**坑**：f-string 注入 JS 必须自带 <script> 包裹，裸文本会被当 body 文本渲染且协议静默失效。
- **09-29 主题定稿（单一「规格书同源」house）**：用户否决全部自创候选（09-27 三张换色系+09-29 三张结构系 editorial/consulting/minimal，批「换汤不换药」「两边内容贴边」「封面没用」）→ 定调=贴自家导出模板 SpecSheet 视觉 token（DEFAULT_SPEC_STYLES：#1668C0 品牌蓝抬头细线/标题块左4px蓝杠/蓝色小节题+发丝线/灰表头#F7F8FA/浅灰圆角KPI卡），**无封面**直接进正文，页边距 18mm；`_THEME_SPECS` 只剩 house，历史 theme 值一律回落。样张 docs/prototypes/artifact-sample-house.pdf。**两 PDF 病灶根因**：①主题 CSS `@page{margin:0}` 在 chromium 顶掉 page.pdf margin 参数→历来全出血贴边（用户抓的），删 @page 规则即愈；②echarts setOption 默认动画，`__CHARTS_DONE__` 同步置位后 page.pdf 抢首帧→折线只画首段/环形缺环体，init 时强制 animation=false。教训：canvas 图表 PDF 验证必须栅格化看图（pymupdf get_pixmap），XObject 计数≠画对。
- **09-29 编辑器「三个自由」**（用户批「标题编辑不了/KPI 增删不了/图表占一行改不了」后定调自研升级，**否决合并导出模板编辑器**——那边是格子(Univer)+token面板(规格书)两种形状，与区块流硬合一个壳=重写三遍；只复用底座=资产注册表+PDF 管线）：①title 区块可钉 title/subtitle/brand_name/brand_tag（留空回落 meta，正文标题+PDF 页眉同源走 `_effective_head_texts`）②全部区块 `span` 4/6/8/12 十二列栅格同宽并排（.rpt-body CSS grid，sec_open 注入 --span）③kpi 拆指标原子目录 `_KPI_METRIC_CATALOG`（六原子含新增 new_month），blk.metrics 勾选/改名/排序，目录随资产元数据下发（list_assets 不剥 metrics），**缺省=全目录（旧模板会多出近30天新增）**④text 块 source=literal 静态文案（blk.text markdown 子集）。调研：pdfme（固定坐标不适合流式报告）/积木报表·UReport2（Java 嵌不进）/jsreport studio（独立 Node）均不引入，抄 Metabase/Superset 12 列栅格模型。样张 docs/prototypes/artifact-sample-flex.pdf（钉标题+KPI删赢单改本周新增+双图半行并排+8/4文本并排+literal 块，pymupdf 栅格化逐项验证过）。
- **09-29 模板对齐七章契约 + 同步方案待拍板**：weekly_opportunity_report（DB id=1 名「商机趋势报告」）blocks 重排 14 块，对齐 flow 126 agent 目标层七章 key（weekly/monthly/half_year/platform/chassis/top_sales/insights——契约住 rules.reasoning_node_config 表 config.target.artifacts[0]，graph 里节点是裸的要查配置表）；版式=编号只给契约七章（01~07 一一对应），KPI 条/概览双图(trend+dist)/口径说明 literal 侧栏不带编号，平台+机箱文本半行并排、机箱玫瑰+业务排行半行并排；top_opps 明细表契约外已移除。**目标层↔模板同步三阶梯（⚠️2026-10-22 用户定调放弃，「一键补齐」不做，留档防重复提议）**：①对接提示黄灯（已有）②推荐先做「一键补齐缺失章节」=输出节点抽屉按钮+后端契约→模板幂等 merge（只加不改不删，title=章节标题、span 继承相邻槽，约半天）③保存结构架构时弹缺口提示。模板编辑器保持流无关，同步动作只住输出节点抽屉。
