**Why:** 列偏移/区域邻接是供应商文件常态，固定列+关键词边界必然踩；引擎语义（耗尽即空、end_mode 优先、表头投票）是防复发的底层约定。

**How to apply:** 碰 Excel 解析错乱先跑 `ExcelParser._locate_regions` 看区域边界与实际表格对不对齐；改解析规则先备份 DB 行；新模板列偏移优先配 header_keywords 而不是改固定列。关联 [[kp-spec-coverage-sparse]] [[quote-export-reveal]]。
