改页面里的某个区块/控件时，不能只改用户点名的那一处——要主动检查整个页面是否合理：控件该放哪张卡、交互模式是否和页面其他控件一致、有没有因为局部改动产生新的不一致。

**Why:** 2026-08-30 员工页滑杆轮：用户发现模型参数被我独立放进收起卡片（应并入指令卡）、滑杆被开关门控拖不动、自定义 radio 是样子货——三个问题都是我只顾实现单点功能没审整页协调所致。用户原话「你改的时候要发挥主动性，主动看整个页面是不是合理」。

**How to apply:** 任何 UI 改动完成后，交付前自问三件事：(1) 这个新控件放的位置是页面语义上最合理的位置吗（还是随手找了个空地）？(2) 它的交互模式（启用方式/反馈方式）和同页其他控件一致吗？(3) 我自己会实际操作一遍验证它真的能用吗？相关偏好另见 [[ui-simplify-dont-add-modes]]、[[feedback-verify-yourself-dont-bounce-user]]。
