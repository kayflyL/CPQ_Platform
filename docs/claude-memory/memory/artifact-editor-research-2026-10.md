产出物编辑器通用化调研（2026-10-02 两轮，报告定稿于 `docs/执行方案/产出物编辑器通用化与AI生成模板-调研报告.md`，**待用户拍板，未动手**）：

- **用户方向演进**：一轮要"模板=样式、内容随 workflow、AI 生成+人工改、先看开源"；二轮追加定调**"PDF 编辑器不拘泥于 PDF，网页本身可导出 PDF，编辑器必须能设计出漂亮的页面"**——一轮"自研薄壳演进"因外观无质变被推翻。
- **二轮修订推荐（§7.7 路径甲）**：**GrapesJS 内核（BSD-3 核验）+ 数据槽位自定义组件（data-gjs-type+traits 绑定契约）+ paged.js（MIT）分页 + 现有 Playwright 出片**；AI 生成=LLM 直接产 HTML（`setComponents` 导入，onlook/bolt 范式）；漂亮三件套=样式检查器+专业预设模板库（Gamma/Canva 做法）+Glass/house token 换肤。三层解耦（样式/骨架/绑定外移 workflow 侧）在新壳原样成立。
- **PoC 清单（最大不确定点=paged.js×流式文档）**：①现有模板 HTML 喂 paged.js 验分页/页眉页脚/表格跨页/echarts 不破；②GrapesJS 嵌 Vue3+3 个槽位组件+文档模式裁剪；③AI 产 HTML→导入→槽位↔契约对账。通过后约 2~3 周集成。
- **license 排雷**（只能参照不能嵌）：jsreport(AGPL+5模板上限)、ReportBro(双 AGPLv3)、**Plasmic(外围 MIT 但 platform/Studio 本体 AGPL+React)**、积木/UReport2(Java+AGPL)。pdfme 固定坐标维持排除。Canva 类 canvas 编辑器(Konva/Tela/OpenDesign/Pika)排除=栅格化出不了矢量 PDF，同 Univer 逻辑。
- **参照不引入**：tmagic-editor(Apache-2.0,Vue3,4.9k★,壳层架构参照但定位移动 H5)、onlook(Apache-2.0,26.6k★,AI×可视化编辑范式)、Editor.js(块 schema 参照)、GrapesJS 官方 Document 形态精装版在收费 Studio SDK。
- **Univer 定调**：仓库已嵌（Excel 导出模板），Doc 编辑器 OSS(Apache-2.0)但打印/导入导出/增强表格在 Pro 收费层+全 canvas 渲染→PDF 场景不换内核；留给 Excel/PPT 产物门届时评估。
- **前置件**：blocks JSON schema 单点化（前后端+LLM 三处共用）；存量 14 块 blocks 模板单向编译成 HTML+槽位标记，渲染端合并成一条管线。
- **craft.js 指名调研（10-03）→ 用户拍板 2B**：设计四点（无头内核/类型化组件树 JSON 与我们 blocks 同构/connectors 行为解耦/useNode）值得无条件学，但 npm 包双重否决=React-only+维护冻结（0.2.12 beta 约两年未发版，issue #747 无人回应）。**2B=craft.js 蓝图 Vue3 自研无头内核+UI 100% 自绘 Glass 风格**（流式文档画布比自由画布简单一个量级）；下游共享（槽位契约/绑定外移/paged.js/Playwright/AI 生成）。
- **2B 第一批已落地（10-03「执行吧」）**：新内核 `frontend/src/components/artifact/useArtifactKernel.ts`（craft.js 四件套 Vue3 镜像+样例渲染器）；`ArtifactTemplateCenter.vue` 编辑器整体重写（画布直接编辑/统一指示条/拖拽幽灵/折叠摘要面板/真实数据预览抽屉，旧结构列表+常驻 iframe 预览+postMessage 高亮已删）；后端 artifact_render.py 补 heading/callout/divider/image 渲染+样式、artifact_templates.py 校验白名单同步。验证：npm build 过、后端冒烟 HTML+真 PDF 163KB、真实前后端浏览器实测存量模板无损往返+全交互（测试时 Vue 补丁是异步的——断言必须 await，别同步读 DOM）；保存 UI 点击被本地 AUTH-off 权限闸挡（save/preview 共用 _validate_blocks 已验证，写库函数零改动），全程零生产写入。**遗留下一批**：paged.js 真分页、AI 生成端点+schema 校验、契约章节键下拉（需契约聚合端点）、绑定层外移（目标态 B）、页面品牌色换肤（需后端 theme 参数）。
- **10-03 晚自验补丁**（用户玩游戏委托自验+原型对账）：补齐两处原型件——预设库抽屉三套（replaceAll 入撤销栈可退回）、序列化查看器 modal；修两真 bug：①.aec-rz CSS 默认 display:none 令 v-show 失效（v-show=true 只清内联→落回 CSS none），placeBar 直接写 style.display 又会被 :style 补丁冲掉→改响应式 rzDisplay 进绑定；②选中变化不触发 placeBar（watch 只盯 blocks）→补 selectionId watch。**测试纪律**：Vue 补丁异步，同步读 DOM 必假阴性；窄窗格挤压布局造坐标假差（加宽再量）；chromium 冷启动 10s+ 别提前判失败。
- **10-03 深夜用户报"画布惨白排版差"**：根因=**scoped CSS 打不进 v-html 子树**（作用域属性只加在模板元素上），全部报表内容样式失效+暗色主题浅灰字继承到白纸=惨白。修法=报表内容样式整体搬到文件末尾**非 scoped `<style>` 块**（aec-* 前缀已命名空间化无碰撞；CSS 变量经 DOM 继承仍可达）。**铁律：v-html 的内容样式必须写非 scoped 或 :deep()。**
- **第二批落地（10-03 晚，契约对账+AI 生成+品牌色）**：①`GET /api/artifact-templates/contracts`（扫活跃流节点配置文档卡；⚠️必须注册在 GET /{template_id} **之前**否则路径被吞返回 422 int_parsing）；②`POST /reconcile` 确定性对账补齐（缺槽追加/未知 key 只报）；③`POST /generate` AI 生成（llm_client.chat_json 一次调用+`_validate_repair_blocks` 确定性修复，真实 LLM 实测 27 块七章全覆盖、**校验器抓到 LLM 把 table 资产塞进 chart 块**——LLM 提议规则裁决闭环实证）；④title 块 accent 品牌色（house 主题主色改 var(--rpt-accent)，⚠️render_report_html 尾部原有 `css = spec["css"]` 二次赋值会覆盖注入，已删）；⑤编辑器：✦AI 生成/按契约校验按钮+契约下拉(a-auto-complete)+色板。本地 AUTH-off 匿名过不了 manager 权限闸（save/reconcile/generate 同），handler 已直连 python 验证；遗留只剩：paged.js、绑定外移。**craft.js 源码精读结论（examples/landing + packages/core/src/events，写内核时照抄）**：①RenderNode.tsx=hover/选中共用一条指示条（组件名+move+select-parent 上箭头+delete），fixed 定位压节点左上沿、滚动跟随、节点加 class 画描边；②createShadow.ts=拖拽幽灵用节点 DOM 克隆 setDragImage（非浏览器默认半透明框）；③RenderEditorIndicator+movePlaceholder=全局唯一拖放指示元素，in-flow 前后横条/float 左右竖条/空容器满宽，error 变红，transition 0.2s ease-in 是顺滑感来源；④Text=contenteditable 绑节点，onChange 500ms 防抖 setProp（非 blur 提交）；⑤Sidebar=Customize+Layers 两个可折叠 SidebarItem 堆叠（55%/45%，互为满高）非 tab；⑥ToolbarSection=MUI Accordion，收起态标题行右侧实时摘要（"15, Medium, Left"），数字全用滑条；⑦Toolbox=connectors.create 携带实例化默认节点的窄图标轨；⑧related.toolbar=组件自带 settings UI。**v3 已搬入**：统一指示条/拖拽幽灵/指示线 0.18s 过渡/防抖内联/折叠摘要分区/页面设置态；select-parent 上箭头与嵌套容器待版式容器区块引入时启用。教训：**做编辑器原型必须先读竞品源码的交互实现而不是看演示自己琢磨**；右栏忌 tab；左色条铁律见 [[no-card-color-strips]]。
- **10-03 趋势流四连真机实测（A 标准30天/B 口语/C 矛盾90天/D 半年窗口）**：四跑全出片、模板管线全生效（KPI/echarts 双图/章节/页码）；**周期跟随实证**：文档卡切 half_year 后 KPI 周期新增 36→187、趋势图横轴拉开半年（当初"数字不随周期变"的反面验证）；**矛盾问法被契约压住**（要90天出30天，封面"配置指定"）。小瑕疵待清：①AI 正文残留 `**` 星号（章节开头装饰性加粗未闭合，可渲染端清洗或 manual_rules 禁）；②KPI"总商机数"(全量190)与环形中心"总商机"(窗口36)同词异口径——KPI 口径遗留又一佐证。**探针坑（复用必看）**：workflow_key 只有「方案助手 DM」发起才生效，群分派按同事绑定覆盖请求流（colleague_turn_service:190）；旧版流程记忆（无 skill_session）被 163 行劫持到需求分析——先 reset_flow_memory 预置 trend 会话；轮询文件卡必须 datetime 解析（字符串比较 'T' vs 空格放旧卡）；渲染样例 PDF 下载 URL 含中文要 quote。现场还原纪律：doc card 配置/线程流程记忆备份→恢复，测试壳商机+线程物理删除（计数回基线 518/323 实证）。

- **方案 v3 终态（10-03 深夜，用户拍板，推翻 v2 绑定外移）**：用户模型=「契约是种子，模板是用户资产」——契约（agent 节点目标层文档卡）只作生成模板的一次性输入（含章节标题拷贝），模板生成后**自包含**（章节映射/资产/窗口全在 blocks），用户改了就按模板、**渲染只看模板**；契约漂移不自动传播，显式「按契约校验」补缺/报失效。**绑定层外移/输出节点绑定视图/AI 双产物方案作废，勿再提议**；输出节点维持"选模板+格式"。**统计窗口/资产/指标构成编辑分区保留**（模板=规格含取数配置；默认跟随数据范围，固定窗口仅限结构语义如半年章 183 天，勿与数据范围抢权——上轮 A 批准的"删统计窗口 UI"不执行）。AI 自由度原则：硬约束仅两类（资产存在/kind 匹配/span 合法 + 章节覆盖），排版/选资产/构成全交设计期 AI，校验器只删不可能不改不好看。三层权威全文在 docs/frontend-pages/settings/artifact-templates.md。遗留仅剩 paged.js；**绑定外移从遗留清单删除**。
