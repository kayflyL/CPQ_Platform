## 维护流（新用例进入知识库）

```
新需求+技术员配置单 → compare_bom 出差异 → 判定（系统错/技术员错/格式差异/数据缺）
   → 更新规则（代码/DB flow/system_config）或更新本文档 → golden 追加 → pytest 全量回归 → 状态置「生效」
```

- 代码索引：
  - 需求分析抽取：`backend/app/services/requirement_intel_service.py`
  - 机型/选件/方案：`backend/app/api/candidate_search.py`
  - 选型配置规则引擎：`backend/app/services/selection_engine.py` + `plan_rule_apply.py`
  - 可配置项：`system_config`（psu_inference / model_family_words / requirement_guide_words 等）、DB flow 节点词表、`compatibility_rules`
