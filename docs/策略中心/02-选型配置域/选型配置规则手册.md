# 选型配置规则手册

> 范围：机型选择 → 基准配置变体排序 → KP 选件 → PSU/背板/线缆派生 → 兼容校验。
> 代码：`backend/app/api/candidate_search.py`（select_models / pick_kp_parts / build_plan）、`services/selection_engine.py`、`services/plan_rule_apply.py`。

## 1. 机型选择（select_models）

| 规则                                                     | 场景                                             | 来源            |
| ------------------------------------------------------ | ---------------------------------------------- | ------------- |
| 系列词表驱动：Orion=AMD、Polaris=信创(KH/兆芯)、Intel               | 需求出现 kh5000/兆芯→ ZS22V2-P 而非 ES22V3-P           | I57 (R12)     |
| 形态推断：机箱尺寸高 XXXmm → U；无 2U/4U → 按系列兜底                   | 4U 需求                                          | I12           |
| **裸 8卡 AI 无平台线索 → ESA24V3-P 与 ZSA24V2-P 双机型都推荐**（用户拍板） | 8卡→直连 +60 仅在需求提到 CPU 时生效；MAX_PLANS 3→6；按机型分组排序 | I88/I90 (R20) |
| 推荐列表上限 6（原来 3 会把双机型截断）                                 | 多变体机型                                          | I90           |

## 2. 基准配置变体排序（_rank_base_config_variant）

| 信号 | 作用 | 来源 |
| --- | --- | --- |
| direct（直通/直连/direct/pass-thru）→ 直连模板 +120，Switch 模板 −60 | 显式直通压过 RAID/存储偏好 | I39/I42 (R8) |
| 8卡具体配置单（gpu≥8 + *N 数量）→ 默认直连模板 | 去掉 form=4U 依赖 | I49 (R10)/I46 (R9) |
| has_raid/存储盘 → 偏好 Switch 模板 | 存储场景 | I39 |

## 3. KP 选件（pick_kp_parts）

| 规则 | 场景 | 来源 |
| --- | --- | --- |
| min_price + spec 过滤（容量/速率/端口/核数/接口/显存） | 通用 | — |
| 介质明确不跨介质替代（HDD≠SSD） | `8T SATA HDD` 不配 SSD | I58 (R12) |
| **CPU 跟随已选机型平台**（platform_series） | 裸配件清单不跨平台 | I89 (R20) |
| 规格属性替代：需求容量库无 → 按 Capacity/Type 数值替代（BOM 标「替代」） | 1.6T → 1.92T | I10 |
| 彻底无替代 → 标 unmatched（前端「需手填」badge） | 9254/RTX PRO 4500/PM893 等 | I30/I65/I87 |
| 指定型号 + 无核数约束 + 库无 → 只 unmatched 不跨平台回退 | KX40000 | I65 (R13) |

## 4. PSU 推断（_infer_psu_wattage）

| 规则 | 场景 | 来源 |
| --- | --- | --- |
| 配置驱动 tiers（system_config.psu_inference）：GPU 数量+高功耗词 → 档位 | 8×RTX5090 → 2700W | I43/R7 |
| 无 GPU → 按 KP 件负载估算（CPU TDP + 常项）取 ≥负载最小标准瓦数 | 「根据功耗选择」→ 1300W 而非无脑 1600W | I5 (R1) |
| 需求显式瓦数 > build_plan 推断（调用方覆盖） | `2* 2000W` | I13 |
| ⭐ 机型标准瓦数取 max(标准, 推断) | ZS22V2-P 标准 1600W vs 推断 1300W | I15/I61（待办，需加字段） |
