# 机型与基准配置档案

> 数据来源：R1~R21 训练对照 + 22 份技术员配置单的 L6 骨架聚合（2026-08-04 只读盘点）。
> 状态：**训练观察，待业务确认**——不作为最终标准，供「机型↔基准配置↔BOM模板」绑定评估用。

## ES22V3-P（Orion 2U12 通用）
| 项 | 观察值 |
| --- | --- |
| 形态/盘位 | 2U 机架式，12×3.5 |
| 背板 | SATA/SAS（纯盘）或 SATA/SAS/NVMe（三模）；有 6NVMe 变体 |
| IO | IO1/IO2 `1*X16+1*X8 FHFL`（主流）；部分单 X8；OCP 1*X8（按需） |
| 散热/风扇 | 2U heatsink ×2；6056 ×6 |
| 电源 | 1300W×2 / 1600W×2（按负载与项目）；2000W（GPU 需求） |
| GPU 支持 | 单宽/双宽 FHFL 卡 1~2 张（RTX Pro 4500 / H100 等），GPU 供电线随卡 |
| 变体 | 纯盘(SATA/SAS) / 三模(NVMe) / 带 GPU 直连——**至少 3 个基准配置/BOM 模板** |

## ESA24V3-P（Orion 4U8卡 AI/直通）
| 项 | 观察值 |
| --- | --- |
| 形态/盘位 | 4U 8 卡机架式，12×3.5（2NVMe 或 4NVMe 变体） |
| IO | 直连/Switch 拓扑**参数化**（每单不同）：`8*GPU+3*X16+4NVME` / `8*GPU+2*X8+OCP X8+2NVME` / `8*GPU+1*X16+1X8+2NVME` / `8*GPU+3X8+2NVME` |
| 散热/风扇 | 2U heatsink ×2；6056 ×6 |
| 电源 | 2700W×4（主流，8 GPU）；2000W×4（低功耗 GPU） |
| GPU | 8 卡：A800/RTX5090/RTX PRO 5000/R9700/5090 等，GPU 供电线 ×8 |
| 变体 | 直连模板2 / Switch 模板3；拓扑随 GPU/OCP/网卡变化 → **直连骨架必须参数化，不能死模板** |

## ZS22V2-P（Polaris 2U12 信创）
| 项 | 观察值 |
| --- | --- |
| 形态/盘位 | 2U 机架式，12×3.5 |
| 背板 | **SATA/SAS（5/8 单）vs SATA/SAS/NVMe（3/8 单）两派 → 至少 2 个基准配置/BOM 模板** |
| IO | IO1/IO2 `2*X8` 或 `1*X16+1*X8` 或 `1*X16+2*X8`；OCP 按需 |
| 散热/风扇 | 2U heatsink TDP≤450W ×2；6056 ×6 |
| 电源 | 1600W×2（众数）；1300W×2（低配） |
| CPU | KH50000 64C / 96C；KH5000 48C（早期） |
| 变体 | 纯盘 / NVMe 三模；系统盘 SATA 默认 |

## ZSA24V2-P（Polaris 4U Switch AI）
| 项 | 观察值 |
| --- | --- |
| 形态/盘位 | 4U 机架式，12×3.5（8SATA/SAS+4NVMe 变体） |
| IO | Switch 拓扑参数化：`10*GPU+2*X8+4NVME+OCP` / `8*PCIe5.0 X16(GPU)+3*X16+4NVME` |
| 散热/风扇 | 2U heatsink TDP≤450W ×2 |
| 电源 | 2000W×4（主流）；2700W（8×5090） |
| GPU | 智铠100DUO / RTX 5090 等 |
| 备注 | 有 4 路兆芯需求落 2 路机型的边界案例（R21），4 路平台缺机型数据 |

## 关键结论（供模板绑定评估）
1. **一个机型多个基准配置是常态**：ZS22V2-P 至少 2（纯盘/NVMe）、ES22V3-P 至少 3（含 GPU）、ESA/ZSA 直连骨架需参数化。
2. **L6 骨架知识当前只存在于 xlsx 与技术员经验**，未进 DB——本轮不蒸馏，后续靠轮次训练继续补。
3. 每个基准配置应绑定独立 BOM 模板，选配流程按「机型 → 需求信号（背板 NVMe? GPU? 直连?）」自动切换。
