# 需求分析节点规则手册

> 范围：`extract` 节点（`requirement_intel_service.extract_keywords`）把**用户需求文本 → 结构化槽位信号**的全部规则。
> 每条规则列：功能 / 代码位置 / 触发场景 / 来源问题 I 编号 / 判定。判定来自训练轮次与技术员配置单对照（技术员也可能错，标注「技术员配置存疑」处不盲从）。
