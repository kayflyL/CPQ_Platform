# CPQ Platform 前端布局与用法规范

> 最后更新：2026-10-21（§4 移动端硬规则八条 + §6 铁律 11「手机端收工必实测」；§5 新增设置类界面范式；文档迁入 docs/前端设计/ 并改名）

## 0. 定位与权威顺序

本规范管 **antd 之上的增量**：间距、字阶、卡片节奏、布局骨架、组件用法决策、项目铁律。antd-vue 已规范的组件行为与交互状态（按钮四态、表格排序、表单校验），本文一律不重复规定——那是重复造规范。

权威顺序（改前端先看，冲突时以此为准）：

1. **[tokens.css](../../frontend/src/styles/tokens.css) —— 值的唯一来源**。所有间距/字阶/颜色/圆角/玻璃配方都是 CSS 变量，改一个文件全局生效。
2. **[视觉风格指南.md](视觉风格指南.md) —— 材质层**。玻璃三级工具类与禁嵌套、overlay 三系语义、投影色、antd 覆盖原则、动效与 signature。
3. **本文档 —— 用法与理由**。规定每个 token 用在哪、为什么，以及用法决策（抽屉 vs 弹窗、表格斑马线何时用）。
4. **[布局与用法规范.html](../prototypes/布局与用法规范.html) —— 可视对照**。用真实 token 渲染的活样张，所见即所得；开浏览器直接打开。

规范语言：**必须**（硬性，违反=返工）、**应**（默认做法，偏离需理由）、**可**（允许）。

| 场景 | 用值 | Token |
| --- | --- | --- |
| 页面边距 / 区块间距 | 24px | `--cpq-space-5` |
| 卡片之间 | 16px | `--cpq-space-4` |
| 卡片内边距 / 分组间 | 12px（密表格卡 12 / 常规 16） | `--cpq-space-3` / `--cpq-space-4` |
| 相关元素间 | 8px | `--cpq-space-2` |
| 紧凑组内（图标↔文字） | 4px | `--cpq-space-1` |
| 卡片标题 | 16px medium / 20px semibold | `--cpq-font-size-lg` / `--cpq-font-size-xl` |
| 页面标题 | 24px semibold | `--cpq-font-size-2xl` |
| 正文 | 14px / 行高 1.6 | `--cpq-font-size-base` / `--cpq-line-height-body` |

## 1. 间距（Spacing）

**一张栅格，六档封闭。** 基准 4px，取值只有六档，布局间距禁用档外值。

| Token | 值 | 语义 | 用在哪 |
| --- | --- | --- | --- |
| `--cpq-space-1` | 4px | 紧凑 | 图标↔文字、badge 内距、组内微调 |
| `--cpq-space-2` | 8px | 元素间 | 相关元素、控件与标签、按钮组 |
| `--cpq-space-3` | 12px | 分组间 | 卡片内 padding 下限、表单行距 |
| `--cpq-space-4` | 16px | 卡片间 | 卡片之间、栅格 gutter |
| `--cpq-space-5` | 24px | 区块间 | 页面边距、区块分隔 |
| `--cpq-space-6` | 32px | 大区分隔 | 页面级章节分隔（少用） |

**三条骨架规则（必须）**：

1. 页面边距与区块间距 = `--cpq-space-5`（24px）。
2. 卡片之间 = `--cpq-space-4`（16px）。
3. 卡片内：标题→内容 12px，内容行距 8px，相关操作按钮组 8px。

**例外（可写字面量）**：≤4px 的光学校正（图标基线对齐、badge 垂直居中微调、hairline 边框补偿）。

**为什么封闭**：节奏感来自封闭尺度。每引入一个档外值，页面节奏就被破坏一次。存量数据佐证：全站 3300 处间距声明，1px~14px 每个整数值都有人用（3px×95、7px×85、9px×64），仅 48% 落在 4px 栅格上——这就是没有尺度的代价。

**Do / Don't**：

- ✅ 相邻两个卡片的间距用 `var(--cpq-space-4)`；❌ 现场发明 10px/14px/18px 的布局间距。
- ✅ 图标与文字 4px；❌ 为对齐某控件用 3px/5px/7px 凑。

**迁移口径**：存量不专项清洗；改哪页迁哪页，微调值（≤4px）不迁。共享面（BomTable、工作台磁贴墙、布局壳）优先迁——迁一处等于迁一片。

## 2. 字阶（Type Scale）

**层级 = 字号 × 字重 × 留白，三者组合出层级，不靠装饰。** 中文正文行高 1.6，标题行高 1.25。

| Token | 值 | 字重 | 用途 |
| --- | --- | --- | --- |
| `--cpq-font-size-xl` | 20px | 600 | 卡片/区块标题 |
| `--cpq-font-size-2xl` | 24px | 600 | 页面标题 |
| `--cpq-font-size-3xl` | 30px | 600 | KPI 大数字（配 `.cpq-reading`） |
| `--cpq-font-size-lg` | 16px | 500 | 小节标题 / 强调正文 |
| `--cpq-font-size-base` | 14px | 400 | 正文默认 |
| `--cpq-font-size-sm` | 12px | 400 | 辅助文字、说明、表格紧凑列 |

**三条规则（必须）**：

1. 页面标题 24px semibold，区块/卡片标题 20px semibold 或 16px medium——一页只用一档主标题。
2. 层级靠组合，不靠装饰：**禁止左侧彩条、渐变大字、文字阴影做层级**（铁律，见 §6）。
3. 数字一律等宽（`.cpq-reading` / `--cpq-num-feature`），价格/规格/计数不用比例字体的数字。

**为什么 12px 是下限**：低于 12px 的中文在小屏与高分屏都不可读；存量确有 11px，改版时收敛到 12px。

## 3. 卡片节奏（Card Rhythm）

卡片是本系统最高频的容器。节奏定死一次，不再逐页发明：

| 位置 | 值 | Token |
| --- | --- | --- |
| 卡片内边距 | 16px（紧凑表格卡 12px） | `--cpq-space-4` / `--cpq-space-3` |
| 标题→内容 | 12px | `--cpq-space-3` |
| 内容行距 | 8px | `--cpq-space-2` |
| 操作区与内容间 | 12px | `--cpq-space-3` |
| 卡片间 | 16px | `--cpq-space-4` |
| 区块间 | 24px | `--cpq-space-5` |
| 悬停上浮 | -2px | —（utilities.css 现行值，勿改） |

**Do / Don't**：

- ✅ 层级靠字号字重留白 + 小圆点/小徽标彩色点缀。
- ❌ 左侧彩色装饰条（`::before` 竖条 / `border-left: 3px` 装饰条）——AI 味，铁律 §6。
- ❌ 卡片左上角大色块、渐变块、左上角标签色带。

## 4. 布局骨架（Page Skeleton）

页面 = 吸顶顶栏 + `.scroll-clearance` 让位 + 内容区。**吸顶一律 `top: 0`**（嵌套滚动容器内 sticky 偏移从 padding 内沿起算，曾双计 72px 压崩工作台——铁律，详见 docs/frontend-pages 相应页）。

**标准列表页**：标题行（24px semibold）+ 工具行（筛选/搜索/主操作按钮）+ 内容。工具行与内容间 16px。

**三栏工作台页**（AI 配置器先例）：卡片满高内滚，页面滚动归零；栏间 16px。

**满高页**：`calc(100vh - 让位)`；hero 页负 margin 垫导航下。

**移动端（≤768 媒体查询；AI 办公室组件级 isMobile 既有 860）**：已有定式——isMobile + 双抽屉/磁贴 + 摘要条，抽屉 portal 全局样式，tabbar-inset 让位，触屏无 hover；切视口必 reload。在此之上，改手机端布局必须遵守以下硬规则（2026-10-21 工作台/行为配置整改沉淀，违反=窄屏不可用）：

1. **禁横向溢出**：收工前手机视口（≤768 reload）验收 `scrollWidth === clientWidth`。弹性/网格容器的尺寸**下限必须包 `min(值, 100%)`**（如 `repeat(auto-fill, minmax(min(420px,100%),1fr))`）——裸像素下限在 360px 视口是硬底，轨道不缩、整页撑破（智能层首版踩坑）。
2. **行式控件防挤压**：label 与控件同行时，label `white-space:nowrap` + `flex-basis` 保底宽，控件给最小可用 `flex-basis`——放不下时**控件换行**，而不是把 label 压成竖排（设置卡 `.set-label` 先例）。
3. **复杂可视化三级降级**：桌面高密度可视化（时间轴/泳道/多列表格）手机端依次「收窄标签 → 减刻度/减列 → 隐藏格内文字」，信息转承到点选后的编辑表单；禁止让格子塞文字（泳道时间轴先例：格内文字在 20px 格里必然竖排成乱码）。
4. **内容型弹层全屏化**：编辑器/看板类弹层 ≤860 铺满 `100vw × 100dvh`、去圆角边框、内容内滚并隐藏滚动条（同事档案 `.em-editor-modal` 先例）；半屏浮层四周必漏出底层内容。
5. **悬浮件让位**：安装横幅(z2100)/AI 悬浮球(z1550) 高于一切内容层——全屏层或 modal 打开时挂 body 类（`em-editor-modal-open` / `office-fullscreen-open`，EmployeeManager / AiOfficeView 先例）将其隐藏，关闭时恢复。
6. **触屏三则**：交互不依赖 hover（hover 只做增强）；可点目标 ≥32px、拖拽把手 ≥40px；手势区按需设 `touch-action`。
7. **滚动条**：窄屏内容区隐藏滚动条（`scrollbar-width:none` + `::-webkit-scrollbar{display:none}`），滑动保留（工作台流程条/同事档案先例）。
8. **断点**：新增页面媒体查询统一 `768`；存量断点（AI 办公室 860、助手面板 760）不专项清洗，改哪页迁哪页。

**服务器链路固定暗色**：详情页/机型目录/门户货架整链固定暗色，免疫主题开关，前端不传 dark prop 之外的主题；原型 HTML 是视觉权威。

## 5. 组件用法决策（Patterns）

**表格**：
- 扫描型列表（>8 行 × 4+ 列）应加斑马纹；编辑型小表不加（视觉噪声）。
- 横向超宽（>12 列或含宽内容列）应固定左侧标识列与右侧操作列。
- 操作列 >3 个动作收进「⋯」菜单（用户/角色页先例）。
- 空态必须给行动出口（尾卡「＋」范式，见 §6）。
- **手机端（≤768）自动卡片化（2026-10-21 定调）**：自研 `RecordTable` ≤768 自动转卡片列表——每行一卡、thead 隐藏、td 靠 `data-label` 显示字段名（首列不放 label 作卡片标题）；新增表格一律沿用该组件即得此行为，不要再写裸 `<table>`。为什么：固定像素列宽在 375px 下每列剩 ~40px，长单号逐字符竖排不可读（商机详情整改根因）。
- **可编辑明细网格（sheet-table 族）手机端**：窄屏横向滑动（`min-width:620px`），**分组列取消 `position:sticky` 左吸**——sticky 列自带底色且会盖住滑过的相邻列首字符（CPU→PU），看起来像色块盖住数据（需求单部件清单踩坑）；触屏无 hover，行删除按钮常显。

**表单**：
- 信息栏常驻可编辑字段：带边框输入框 + `width: 220px`（用户嫌隐框丑、auto-complete 会塌缩——已定调）。
- 创建/编辑：字段 ≤3 且行内可完成 → 行内/弹窗；否则抽屉或页面。禁止嵌套弹窗。
- 标签对齐：短表单（≤6 字段）顶对齐，长表单右对齐（antd 默认右对齐即为此设计）。
- 必填标识、校验文案、触发行高亮一律用 antd 内建，不自造校验 UI。

**抽屉 vs 弹窗**：详情/大型编辑（内容 >半屏）用抽屉；确认/小型表单（<3 字段）用弹窗；流程性多步用弹窗 stepper。**禁止弹窗内再开弹窗**（嵌套 z-index 与焦点管理不可控）。

**弹窗口径**（权威源 `constants/modalPresets.ts`，禁止组件自写宽高）：
- 宽度四档：`full`=min(1560px, 96vw) 三栏工具型（解析预览）；`sheet`=min(1200px, 96vw) 工作台级（需求单/方案/成本表/归档/分享）；`viewer`=min(760px, 92vw) 只读明细；`action`=min(560px, 92vw) 小操作表单。
- 一律 `centered`。为什么：antd 默认 `top:100px` 非居中，弹窗坐得低、底缘被视口裁掉必须滚动（2026-10 详情页整改根因）。
- 工作台级 body 用 `maxHeight: MODAL_BODY_MAX_HEIGHT`（`calc(100vh - 120px)`）内滚。为什么：居中后 header+内容边距约 95px，-120px 保证满高时底缘仍留 ~25px 余量。
- 表面壳统一 `wrap-class-name="portal-sheet-modal"`（玻璃化表面在 `styles/antd-overrides.css`）。
- **手机端（≤768）全屏化（2026-10-21 定调）**：full/sheet/viewer 三档一律经 `components/common/ResponsiveModal.vue` 调用（传 `tier` 替代 `:width`），≤768 自动转**全屏页**——`100vw×100dvh` 去圆角、左上角返回按钮、与系统返回手势/浏览器后退同步（`composables/fullscreenModalHistory.ts` 压栈，嵌套安全）；`action` 档保持居中小窗。为什么：手机上居中浮层既占不满也没上下文，返回手势不收敛会"关不掉退出不了"（商机详情整改根因）。实现四坑已填：透传 attr 会覆盖显式绑定（组件 `inheritAttrs:false` + 剥冲突键）、antd 有 `title` prop 时无视插槽（全屏态剥掉 prop）、antd 居中行盒计算会把满高弹窗推出视口（`position:fixed` 显式四边压死，**禁用 `inset` 简写**——老内核不认）、**antd-vue 4.2 在 `.ant-modal` 与 content 之间垫了无类名 div，content 的 `height:100%` 会对着 auto 层解析成内容高（弹窗塌成一条 28px body 的根因），content 必须直接给 `100vh/100dvh` 显式高度**。全屏层打开时挂 `body.cpq-fs-modal-open` 隐藏 AI 悬浮球（硬规则 5 同源），**并隐藏页面滚动条**（桌面经典滚动条占列宽，fixed 全屏弹窗盖不住，右侧会露缝）；全屏 body `overflow-x:hidden` 一刀切——弹窗内任何块不允许横向滚动，可编辑网格在自己容器内滑；**全屏层内关闭浏览器默认聚焦描边**——弹窗打开时 antd 把焦点交给容器，蓝色 outline 贴着屏幕边被裁成一条"色差线"（商机详情整改踩坑，触屏无键盘导航，描边纯属噪声）。
- **特殊工具弹窗移动端降级**：解析预览（三栏核对/列绑定）手机端明确提示"请在电脑端完成"，不为它硬适配。
- **全屏内容层去卡片壳（2026-10-21 定调）**：全屏页本身就是容器，`.cpq-fs-modal` 内的一级玻璃卡平铺满宽（去边框/圆角/底色），卡头不得与页标题重复（页标题带版本号等信息，卡内只留说明与状态徽章）；主操作统一放 footer 底栏（桌面右聚，手机端全宽等分、拇指可及），不埋在内容流里。为什么：卡中卡+双标题在手机上浪费两侧空间还打断阅读动线（需求单弹窗整改根因）。

**反馈升级链**（轻 → 重）：message（轻提示，自动消失）→ notification（右上角，需用户注意到但不阻塞）→ Modal.confirm（阻塞决策）→ 危险操作 = Modal.confirm + 输入确认（用户/角色页 Danger Zone 先例）。

**空态**：必须给行动出口——网格尾虚线「＋」卡/通栏虚线条（空态常驻），标题行不放「+ 添加」链接按钮。

**语义色**：蓝=主操作/链接/选中；绿=成功/在线；琥珀=警示（不阻断，warning 不阻断=手改优先）；红=危险/失败。马卡龙语义色 token 已有（`--cpq-color-success/warning/danger`），浅暗主题各有前景/背景对，一律用 token 不裸写。

**设置类界面（Settings UI）**——配置/管理页的参数区统一用「设置卡」范式（Win11 设置页先例；行为配置页 2026-10-21 整改定调，参考实现 `OfficeBehaviorEditor.vue` 智能层 `.set-cards/.set-card/.set-row`）：
- 结构：一个功能 = 一张 `set-card` 卡（底色 `--cpq-glass-1-bg` 档、圆角 lg、**无边框**），卡头 = 「开关 + 名称 + 说明」，卡内参数 = **行式控件**（`.set-row`：label 左、控件右、细分隔线隔行）。层级只有 页面 → 卡片 → 行 三层。
- **禁止字段级描边**：不给参数加边框/底色小块（sfield 字段块、rule-card 框中框已否决——层级靠底色差与分隔线，靠加框就是贴创可贴）。
- **禁止玻璃嵌套**：卡片外层用透明布局容器（`.be-section--plain` 先例），卡片是唯一玻璃层（§3.4 同源）。
- 网格：`repeat(auto-fill, minmax(min(420px, 100%), 1fr))`。**minmax 下限必须包 `min(420px, 100%)`**——裸 `420px` 在 360px 视口是硬下限，轨道不缩、整页横向溢出（踩过：智能层首版）。
- 全屏层让位：全屏层（antd modal z1000 / 管理面 z900）打开时挂 body 类（`em-editor-modal-open` / `office-fullscreen-open`），让 z 更高的安装横幅(2100)/AI 悬浮球(1550)隐藏（EmployeeManager / AiOfficeView 先例）。
- 为什么：设置页可读性来自稳定的行结构；裸文本+控件混排的 flex-wrap 在窄屏必然失散（行为配置整改根因），补丁式加框只会框中框。

## 6. 铁律清单（Hard Rules）

从各条实战教训收编，全文硬性。违反=返工。

1. **禁左侧彩色装饰条**：一切卡片/KPI/callout/原型，层级靠字号字重留白，彩色只做小圆点/小徽标。写 CSS 前自查 `::before` 竖条与 `border-left` 装饰条；deck-line 仅标题级水平线。
2. **磁贴/列表预览禁圆点项目符号**：靠字号+字重+透明度做层级（WP/Metro 先例）。
3. **图表色不能用 CSS 变量**：chart.js/echarts 是 canvas 渲染读不到 `var()`，图表色走 `useChartTheme` composable 给真实值；echarts `use()` 必须数组形式。
4. **服务器链路固定暗色**：详情页+机型目录+门户货架整链固定暗色，免疫主题开关。
5. **吸顶让位用 `.scroll-clearance` 非 padding**：嵌套滚动容器内吸顶一律 `top: 0`；满高页 calc 减让位。
6. **原型=规格书**：原型确认后落地不许自砍范围；做不了的先说清让用户拍板，别先斩后奏写「不做」清单；落地前逐条清点原型功能。
7. **规范字段标签先查种子**：商机字段中文标签权威源=init_business_fields.py 种子，起列名/表头前先查。
8. **数字等宽**：价格/规格/计数用 `.cpq-reading` / `--cpq-num-feature`，不用比例数字。
9. **v-show 挂多根组件静默失效**：v-show 对 fragment 根不继承；动模板结构后必查单根；症状「面板出现在不该在的 tab」先查多根。
10. **改 UI 须主动审整页**：改页面某控件要主动看整页合理性（位置归属/交互一致性/自操作验证），别只补丁点名那处。
11. **手机端收工必实测 + 禁横向溢出**：改过手机端布局的页面，收工前切手机视口 reload 验收（横向 `scrollWidth === clientWidth`）；响应式尺寸下限一律包 `min(值, 100%)`。为什么：360px 视口下裸像素下限/固定栅格必然撑破（行为配置智能层两次踩坑）。
