架构实体 —— 登场的远不止引擎 / 工具 / 节点

现场入口
dispatch_flow_turn 按 entity_binding 分流两台机器：sandbox→需求分析 / real_bound→事务内核
出场 P0
大脑 LLM
原生 Function Calling 回合；只提议不落地，带全现场 + 本节点白名单
出场 P1–P3 ②
引擎·编排壳
skill_chat 回合机 + skill_plan_runtime：prepare_step / validate_step_end / final_gate / run_compose——壳不认识任何节点
出场 全程 ①③④
节点插件
skill_node_plugins：DefaultNodePlugin → _FillNode / _ModelNode / _KpNode / _ComposeNode。每节点专属行为，插槽 prepare / validate / bridge_ctx / wire_result / delivery_gap / stuck_gap / artifact_contract；新增节点 = 注册插件，壳零改动
出场 引擎格的实际执行者
工具（白名单）
按节点下发：fill_requirement · choose_model · query_parts · select_parts · apply_kp_picks · ask_user · catalog_search · query_data。AI 唯一写通道，确定性规则埋在落地口
出场 大脑格里的 code 名
TOOL_CTX 桥
skill_tool_context（ContextVar）：插件 bridge_ctx 把候选池 / 行清单 / ext / save 下发给工具；任务态与身份同取于此
出场 隐形管道
DB wiring 接线契约
reasoning_node_default 种子的 wiring 段：wire_result 读它把工具结果接进引擎产物——池内再核验 → lock_handler 落锁 → 进度写回方案草稿；换工具 / 落锁器 = 改 DB 一处
出场 收口瞬间
底座件（共享确定性件）
slot_contract（登记表 schema / 键归一 / 必填闸 / 前提闸）· part_selector（检索+落地，unmatched 白盒）· 候选池构建 · capabilities 语义补全——被工具与插件复用
出场 P1–P4 金框格
目标层契约
skill_target_contract ← 画布 target.artifacts：每节点产物契约文本（artifact_contract）注入大脑
出场 随 prepare 下发
数据层
reasoning_state（ext + 节点私有态）· KP 库 · 在售目录 · 需求规则页 · reasoning_flow——单一权威源，状态在库案台现算
出场 时间轴底行

实体怎么连 —— 四条回路 + 一条配置权威

A · 决策回路（大脑 ⇄ 工具）
大脑原生 Function Calling · 只能调本节点白名单内的工具
工具结果 / hint / not_in_pool 拒绝（快反馈，大脑当场改）大脑
B · 编排回路（壳 ⇄ 插件）
编排壳plugin_for(key)：步前调 prepare · 步末调 validate（壳零节点知识）节点插件
节点插件delivery_gap / stuck_gap 出路卡（候选卡 / 自选卡结构化交客户）现场客户
C · 接线回路（工具结果 → 引擎产物）
节点插件bridge_ctx：候选池 / 行清单 / ext / saveTOOL_CTX 桥下发工具
工具结果wire_result读 DB wiring · 池内再核验 → lock_handler 落锁引擎产物
D · 终审回路（AI 不在场）
编排壳final_gate 三道闸 · run_compose 确定性组装BOM 草稿落库
E · 配置权威（画布可配 · DB 权威）
reasoning_flow DB节点链 · 每节点工具白名单 · wiring · 目标层契约编排壳 + 节点插件
F · 底座复用（谁在调底座件）
工具调用底座件同样被插件调用（如 slot_contract 校验、候选池构建）节点插件

确定性底座的 5 个出场时刻——每一次都是 AI 零通道

P1·落地 键归一：LLM 产出规范化后才入库 P2·预处理 候选池构建：取值域由引擎给定 P2·工具 池外拒绝 not_in_pool：白名单硬闸 P3·工具 价格规格库回填 + unmatched 白盒点名 P4·终检 三道闸 final_gate + 确定性组装 run_compose
产出：BOM 方案草稿 → 落商机详情页「方案配置」节点下游交付转报价（事务内核 real_bound）接棒——同一哲学的两台机器
大脑（提议） 工具（AI 必经落地点） 编排壳（把关） 节点插件（节点专属行为） 底座（算数） 失败回喂 / 硬拦截 数据（事实）
